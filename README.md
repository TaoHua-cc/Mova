Mova 是一款沉浸式私人影音客户端，同时支持 **Windows** 与 **Android**。它把 TMDB 中文影视资料、Emby / Jellyfin / WebDAV 媒体来源、Trakt 观看记录与 libmpv 播放器整合进同一套海报背景的界面里，从「找片」到「看完」都在一个窗口内完成。

## 功能特性

### 首页与发现

- 顶部为海报轮播，随当期内容自动轮换，背景整幅铺开当前海报。
- 继续观看：直接接上一次的进度，一键续播。
- 向下滚动接上发现栏目，栏目顺序与卡片样式都可自定义。
- 进入软件即先呈现本地已缓存的内容，随后在后台比对更新并就地替换，不必等网络。

### 搜索

- 默认检索 TMDB 中文影视资料，也可一键切换到已连接的媒体服务器，搜实际片源。
- 输入即出结果，海报与信息随手补全。

### 详情页

- 季与剧集、已看进度、下一集播出安排一屏呈现。
- **资源聚合**：把同一部作品在所有已连接服务器上的版本汇总成卡片，可按「最优结果」或「全部版本」浏览，选一张直接开播。
- 音轨与字幕、演职人员、艺术图、相似推荐。
- 再次打开同一部作品时，先铺出上次的结果，再在后台核对更新；短时间内反复进出不会重复请求服务器。

### 播放器

- 基于 libmpv，支持硬件解码、外挂字幕、音轨切换、弹幕与章节。
- 播放位置记忆：退出再进，从上次的位置继续；也可设为只保存在本机，不上报服务器与 Trakt。
- 手势：单击呼出控件、双击播放 / 暂停、横划快进快退、左半屏调亮度、右半屏调音量。
- 亮度、音量、快进快退以 HUD 回显，位置抬高，不遮挡字幕。
- 工具栏按钮的顺序与显隐都可自定义，倍速等常用入口一键直达。
- 播放时屏幕自动常亮。
- 播放即缓存：整份视频与当集弹幕会存到本机，下次打开直接播本地文件，弹幕也不必再等接口匹配。
  缓存上限在设置页可调，Android 还能把「无线局域网」与「移动数据」分开设置（移动数据默认不缓存）。

### 行迹

- **追剧日历**：整合待看内容、Trakt 记录与剧集更新，含下一集播出安排。
- **片单**：自建片单，详情页一键加入。
- **服务器**：Emby / Jellyfin / WebDAV 多服务器并存，随时切换。
- **多站评分**：经服务端 MDBList 聚合各站评分，按来源分别展示原始分制；暂无数据时留空，不占位。
- **更新**：设置内可手动检查新版本，也可以在启动时自动检查；发现新版本会提示，下载与安装都在应用内完成。

## 界面与设计

- **海报背景 + 玻璃面板**：以当前作品的海报作为整页背景，内容浮在玻璃质感的面板之上，模糊与描边让层级自然分开。
- **外观可选**：深浅两套底色，另有六种色调预设（石墨、曜黑、靛蓝、松绿、暖砂、紫罗兰），卡片与按钮的材质会随设置整体联动。
- **统一栅格**：桌面与移动共用一套页边距规则，宽屏自动分两栏，窄屏收成单栏，不改变内容本身。
- **统一动效**：时长、曲线、按压缩放与触感使用同一套规范，页面切换与浮层出现 / 消失保持一致节奏。
- **平台自适应**：桌面端提供窗口按钮与鼠标悬停反馈；移动端为沉浸式全屏、手势操作与触感反馈。同一页面在两端的文案也会各自贴合平台习惯。
- **设置页**：窄屏为横向胶囊导航 + 单栏，滑动时胶囊与内容联动；宽屏为左侧分类 + 双栏。
- **播放器浮层**：所有回显收成同一款横条 HUD，视觉上与界面其余部分保持同一材质语言。

## 支持的媒体来源

- Emby
- Jellyfin
- WebDAV
- TMDB 中文元数据
- Trakt 观看记录与待看同步

## 系统要求

- **Windows**：Windows 10 或 Windows 11（64 位），支持 D3D11 的显卡驱动
- **Android**：Android 7.0（API 24）及以上，arm64-v8a / armeabi-v7a / x86_64
- 访问 TMDB、Trakt 或个人媒体服务器所需的网络连接

安装包请从 [GitHub Releases](https://github.com/TaoHua-cc/Mova/releases) 获取。

## 隐私

服务器密码、访问令牌与同步凭据只保存在本机，不会上传到任何地方。

观看记录默认保存在本机，同时同步到媒体服务器与 Trakt，方便换设备接着看。服务器页的「观看记录只保存在本机」
可以关掉这个回写：播放进度、续播位置与剧集进度全部留在本机，服务器媒体照常播放，服务器上已有的记录也照常读取。

视频与弹幕缓存同样只写本机，不会回传给服务器或任何第三方。设置页「缓存与数据」里能看到各自占用多少，
也可以单独清理视频缓存或弹幕缓存，与元数据、海报缓存互不影响。
