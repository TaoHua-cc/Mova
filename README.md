# Mova 映迹

<p align="center">
  <img src="app/assets/mova-logo.png" alt="Mova 映迹" width="128" />
</p>

Mova 是一款面向 Windows 与 Android 的私人影音应用。连接个人媒体库与影视资料，一处发现内容、管理追剧进度，并在熟悉的设备上继续观看。

## 功能介绍

### 发现与搜索

- 首页展示精选海报与继续观看内容，打开后可先浏览本机已有内容，再自动获取更新。
- 发现页汇集热门榜单与自定义栏目，可调整栏目顺序、显示状态和卡片样式。
- 搜索影视资料，也可搜索已连接媒体库中的实际影片与剧集。
- 影片海报、剧情简介、演职人员、多站评分与相似推荐集中呈现。

### 详情与追剧

- 按季度浏览剧集、观看进度与后续播出信息。
- 汇总同一作品在多个媒体服务器中的可播放版本，选择资源即可开始播放。
- 使用收藏、待看片单与追剧日历整理想看的内容，并查看剧集更新安排。
- 在不同设备间同步观看记录；也可选择仅保存在本机。

### 播放体验

- 支持字幕、弹幕、音轨、倍速、章节和播放进度记忆。
- 可自定义片头、片尾跳过位置，并优先使用个人设置。
- 播放器控件的顺序与显示状态可按习惯调整；常用操作支持手势与快捷交互。
- 视频与弹幕可缓存到本机，便于继续观看和再次打开时快速使用。

### 个人媒体与隐私

- 连接 Emby、Jellyfin 或 WebDAV 媒体库，并同时管理多个媒体来源。
- 支持 TMDB 影视资料与 Trakt 观看记录、待看清单。
- 服务器密码、访问令牌、播放记录及缓存由用户按设置管理；可关闭观看进度回写，仅保留本机记录。

### 视觉与设备

- 海报首页与流动渐变背景相衔接，内容页面使用统一的玻璃质感控件与柔和动效。
- Windows 与 Android 提供适合各自屏幕和操作方式的布局。
- 支持 Windows 10/11（64 位）及 Android 7.0 或更高版本。
