# Windows 自动跳过提示

单行：`3 秒后跳过片头    取消`。无图标、分隔线、进度线或二级按钮。

- 高 34，圆角 17；宽度按统一字体实际测量。左内边距 12，文字至取消区间距 8，取消区 40，无空数值列。
- 使用播放器内置统一字体 MakeInterfaceFont：正文 13，操作 12，常规字重，不使用 Segoe UI 独立字体。
- 直接复用播放器菜单的 FillStaticPlayerMenuSurface 与 StrokeStaticPlayerMenuEdge；中性 RGB(88,96,98) 底材遮蔽随外观 0–40 从约 6% 平滑增加至 98%，中点 52%。柔和反光与细边固定，不染蓝、不增加白雾，不获取任何背景图像。
- 不采样播放画面；随系统 DPI 缩放。
- 左侧距播放器 32，位于底部控件上方 24；小窗口限制在可用区域内。
- 倒计时只更新整数秒，固定宽度；取消仅消费当前片段，不改变设置。
- 成功显示“已跳过片头”；取消显示“本次不跳过”。

`auto-skip.svg` 是可编辑的精确素材；运行时使用原生矢量绘制，不加载位图。
