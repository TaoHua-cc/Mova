# 一比一实现规范

状态：设计稿，尚未接入运行时。设计基准 1600 × 900 逻辑像素；Windows 原生播放器按 DPI 比例缩放，最小可用视口 960 × 540。此处的演示影片名、季集、时间与字幕均仅供设计图呈现，不得写入生产逻辑。

## 材质统一

与应用现有玻璃外观设置共用 `g_glass_blur`（0–40）。播放器**不从视频帧、窗口或 DWM 背景采样**。对顶部控件、底部控制岛、操作提示及所有二级菜单调用同一个 `DrawStaticPlayerGlass(rect, radius, intensity)`，绘制顺序固定：

1. 固定中性雾面渐变，上 `#34393F` / 下 `#1B1F24`。基准 alpha 为 0.82 / 0.88。
2. 上部 38% 内的白色微光，最大 alpha 0.17，并从上到下衰减至 0；不能形成硬边或色带。
3. 1 px 外描边，白色 alpha 0.34；1 px 内缘，白色 alpha 0.13。
4. 离屏静态柔影：y=12、模糊半径 32、黑色 alpha 0.23。只在表面状态变化时重绘，视频逐帧播放不触发材质重建。

基准强度为 `g_glass_blur=20`。其他设置值仅通过预计算颜色表线性插值：`t=clamp(g_glass_blur/40,0,1)`；顶部 alpha `0.72+0.20t`，底部 alpha `0.78+0.18t`，高光 alpha `0.12+0.10t`，描边 alpha `0.28+0.12t`。设置为 0 仍保持固定雾面以保证字幕/画面对比度；40 为最厚材质。设置变化只重绘 UI 层，不更新视频采样缓存。必须避免现有 `DrawGlassBackdrop` / `PrintWindow` / `UpdateGlassBackdrop` 在播放器 UI 触发。不要把 CSS `backdrop-filter` 当运行时实现。

透明渐变 + 细噪点可使用初始化时生成的 128 × 128 灰度 alpha tile（随机种子固定，像素 alpha 0–3），在材质区重复铺设；这是可选抗色带，不采样视频。不能为每个按钮或每帧重新生成噪声。若 GDI+ 渐变已足够平滑，可省略此纹理。

## 覆盖状态

操作提示：时间跳转、拖动预览、音量/静音、亮度、倍速、播放/暂停、上一/下一集、自动跳过、成功、加载、错误。提示共用同一材质函数。数值与轨道平滑跟随输入；快速切换提示时保留容器中心点，先交叉淡化内容再调整宽度，禁止交叠两个旧提示。普通提示持续 1.4 s；错误持续 3 s 或到用户下一操作；数值更新使用 80–120 ms ease-out，整体进出 160 ms ease-out，减少动效设置开启时遵循系统设置直接切换。

按钮状态：默认仅玻璃底；悬浮增加白色 alpha 0.12；选中增加白色 alpha 0.22 与 1 px 内框；主播放/暂停为白色 alpha 0.94、深色图标。禁用降低内容 alpha 而不改变按钮宽度。焦点使用 2 px 高对比外环，键盘方向键与 Enter 逻辑沿用现有实现。

菜单：主菜单、字幕/音轨、画质、画面、倍速、选集、弹幕、章节、诊断均使用相同材质；宽度可由既有内容约束调整，但行高、边距、选中状态和字体保持一致。菜单内部滚动条隐藏但仍可鼠标滚轮/触控板/键盘滚动。任何真实来源失败、无字幕、无章节等必须显示可信空态与恢复入口。禁止把演示数据写入应用。

## 与现有代码映射

Windows：`windows/native_player/main.cpp` 中 `FillGlassSurface`、`FillHintGlassSurface`、`PaintPanelContent`、工具栏按钮绘制应收敛到同一个静态材质入口。把当前菜单和按钮使用的 live `use_backdrop=true` 路径改为固定材质；操作提示复用同样的材质层，而不是各自定义渐变。现有 `GlassLevel()` 用作外观设置输入，不新建持久化键。`UpdateGlassBackdrop` 如无非播放器用途，应从播放器帧循环移除，至少播放器 UI 绘制不再调用。UI 更新必须是增量无阻塞，不能回归播放器卡顿。

Android：仍由 Flutter 播放页承载，复用 `lib/src/brand.dart` / `motion.dart` 的玻璃与交互动效令牌；保持触控目标至少 48 dp，长按对应 Windows 右键。若仅实现 Windows 设计，必须在交付时明确两端差异并做 Android 人工核验。

## 验收

1. 亮暗视频画面下控件、提示和菜单质感一致，均无逐帧变化或视频画面局部影像穿进玻璃层。
2. 连续拖动进度、调音量、切倍速并打开菜单时，提示位置和数字稳定，不截断、不闪烁、不重叠。
3. 全局玻璃设置 0/20/40 各检查一次；UI 材质强弱有明确变化，视频播放帧率及操作延迟不因菜单开闭下降。
4. 1600 × 900、960 × 540、2× DPI、键鼠和触控板检查遮挡、文本完整性、可滚动菜单和键盘焦点。
