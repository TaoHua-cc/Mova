# Mova Windows 原生播放器控件一致性

## 基本信息

- 标题：播放器控件状态、二级菜单键盘操作与提示稳定性
- 日期：2026-09-30
- 状态：已完成
- 影响平台：Windows
- 关联 Issue、提交或版本：本地开发

## 背景与问题

原生播放器已具备统一静态雾面二级菜单、进度拖动预览、提示单槽和鼠标悬停动画，但播放器面板的方向键仅滚动、无法聚焦/确认菜单项；按钮按下反馈不完整。快速连续操作时需要确保提示保持单槽并平滑更新，不抖动布局或引入视频画面采样。

## 目标

- 保持现有圆形按钮尺寸、位置和图标，补足按下反馈与可辨识状态。
- 让所有二级菜单可用方向键聚焦、Enter 确认、Escape 关闭，并保证焦点行可见；鼠标操作维持原行为。
- 控件提示继续共用单个窗口和固定雾面材质，连续变化仅更新内容/进度，不采样视频、避免尺寸和位置跳变。
- 保持 seek 拖动时拇指即时跟随、松手后才提交一次 seek，避免网络流拖动产生大量 Range 请求。

## 非目标

- 不改播放器按钮布局、图标体系、视频解码/缓存、键位偏好或 mpv 命令语义。
- 不在播放器 UI 增加逐帧视频背景模糊或额外渲染线程。

## 用户流程与界面

- 鼠标悬停和按下使用原圆形控件上的轻量亮度状态；不触发布局位移。
- 打开二级菜单后可用上下方向键移动焦点、Enter 触发、Page Up/Down 翻页、Escape 关闭；键盘焦点项滚入当前视口。
- 连续拖动进度或音量时，提示数字/进度实时更新，胶囊锚点与尺寸稳定。
- 保持现有触控/指针到鼠标消息路径，不引入额外触控依赖。

## 数据与接口

- 输入与输出：菜单项和控件状态由当前播放器实时状态提供。
- 数据来源：Windows 原生播放器本地状态与 mpv 属性。

## 风险与回滚

- 主要风险：原生菜单的焦点行与鼠标悬停共享绘制状态，必须在鼠标重新移动时立即归还鼠标控制。
- 监测方式：Release 构建与菜单逐项人工验证。
- 回滚步骤：回滚本规格列出的原生播放器/文档变更即可，无数据迁移。
