# 详情页剧集二次点击播放与状态反馈

- 标题：详情页剧集选择、播放与状态可见性
- 日期：2026-09-29

- 关联 Issue、提交或版本：无

## 背景与问题

详情页剧集首次点击会选中剧集并搜索该集资源，但选中后再次点击没有播放行为。全部剧集弹窗对已播放状态仅显示一个对比度较低的勾号，鼠标悬浮时也缺少明确的行边界反馈。

## 目标

- 已选中剧集再次点击时，使用该集已找到的可播放资源开始播放。
- 选中状态与鼠标悬浮状态通过稳定的白色描边和轻微底色区分。
- 已播放状态使用易读的文字胶囊和高对比勾号表达。

## 非目标

- 本次不改变剧集资源搜索、观看进度存储或跨端同步规则。
- 本次不改变播放器选集面板。

## 用户流程与界面

- 宽屏鼠标：点击未选集会选中并搜索；点击当前选中集会播放其已找到的资源。全部剧集弹窗中悬浮行显示白色描边，选中行保持更明显的描边与底色。
- 窄屏/触控：首次点按仍选择，第二次点按已选集播放；长按标记菜单保持现有行为。
- 没有可播放资源时保留页面，并说明仍在搜索或未找到资源。
- 已播放行显示绿色“已播放”胶囊；未播放行显示播放图标。

## 数据与接口

- 输入与输出：复用当前选中的剧集与 `_resources`。
- 数据来源：现有服务器聚合资源与观看进度。
- 新增/修改字段：无。
- 持久化键或缓存格式：无变化。
- 网络接口、超时与错误处理：无新增接口。
- 隐私与敏感信息：无变化。

## 技术方案

- 修改 `metadata_detail_page.dart` 中详情页剧集目录回调与“全部剧集”列表。
- 复用 `_play` 起播路径、当前资源结果、Mova 动效时长与上下文菜单。
- 已选中再次点击时只选择当前集资源，不重复触发服务器聚合。
