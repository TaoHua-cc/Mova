# 追剧日历卡片画面与 Trakt 连接

## 基本信息

- 标题：追剧日历卡片画面与 Trakt 连接
- 日期：2026-09-24
- 状态：已完成
- 影响平台：Windows / Android
- 关联 Issue、提交或版本：无

## 背景与问题

追剧日历卡片底部的待看/弃剧两个按钮在卡片中部附近，视觉位置不符合预期；竖版海报显示不够清晰，卡片也没有该剧横版图像作为背景。日历右上角已有 Trakt 设备码 OAuth 入口，但需要明确保持“浏览器授权后自动回连并刷新”的体验。

## 目标

- 将两个卡片操作按钮稳定对齐到右下角。
- 使用更高分辨率竖版海报，并在有真实横版图像时以渐变方式融入卡片背景。
- 缓存/合并日历事件时保留横版图像信息；旧缓存可继续读取。
- 保持日历的 Trakt 浏览器设备授权、自动令牌交换、保存和刷新流程。

## 非目标

- 不更换 Trakt OAuth 协议，不增加本地回调服务器或凭据。
- 不为每张卡片额外调用 TMDB 详情接口，不添加虚构图片。
- 不调整日历数据源、去重规则或时间推断。

## 用户流程与界面

日历卡片保留左侧竖版海报；同剧横版图像铺在卡片背后，并向信息区渐隐，文字保持清晰。待看和弃剧操作位于卡片右下角。无图时保持原有材质和可信占位。点击未连接状态的 Trakt 按钮后打开授权浏览器；授权成功自动连接并刷新日历，失败可重试。桌面宽/窄窗口和触控尺寸均需检查。

## 数据与接口

- 新增可空 `backdropUrl`，来自 Trakt show fanart 或已缓存 TMDB 元数据。
- 持久化使用现有日历 JSON 缓存键；新字段可空且旧记录可读。
- 不新增接口/密钥；Trakt 继续使用现有设备码 API。

## 技术方案

在 `TraktEvent` 中序列化可空横版图像 URL、在 Trakt 日历解析 `images.fanart.full`，并在事件合并时保留可用图像。卡片内使用现有图片缓存组件和品牌玻璃材质；TMDB 海报请求规格提升至适合卡片的尺寸，背景图做尺寸约束。移除底部行错误的弹性占位，让按钮靠右。

## 兼容与迁移

- 旧缓存可继续读取，`backdropUrl` 缺失时使用原有卡片样式。
- Windows 与 Android 共享实现；浏览器通过现有 `WindowHost.openUrl` 打开。
- 不修改服务端协议、持久化键或 OAuth 凭据。
- 回滚安全：新增字段可忽略。
