# Windows 播放器二级菜单对齐 Android

- 日期：2026-10-01
- 状态：已实现并本地部署，待用户实机验收
- 平台：Windows 原生播放器；Android 作为样式参照，不重新部署

## 目标与范围

保留现有圆形控件和真实播放器功能，二级菜单统一 Android 的固定深色玻璃（#1E2026、alpha=.72+blur/200）、24px 外圆角、440px 标准宽度、20px 内边距、18px 顶部标题与圆形关闭按钮。标题固定，内部内容可滚动但不显示滚动条；声音与字幕分开，轨道行不显示多余前置图标和未选圆圈，已选显示勾。Windows 鼠标悬停、方向键与 Escape 保留。

## 实现与兼容

复用原生 PanelItem、PanelMetrics、GDI+ 绘制和统一布局命中函数，首项 Header 固定，其余分组仍在内容区。不读取视频帧、不引入 Flutter 叠加播放器、不改解码或持久化、网络协议、版本。Windows 选项数量与 Android 不同，保留平台实际支持的功能，不虚构选项。
