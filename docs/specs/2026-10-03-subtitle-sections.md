# Windows 字幕分类与季集匹配

## 背景与目标
- Windows 未实现主字幕、字幕搜索、本地导入分类；片名搜索不能保证当前集。
- 复用原生面板分组、系统文件选择器和 SubHD 服务，不引入依赖或实时玻璃采样。
- 从结果的发布文件名判断 SxxExx、中文季集；明确不匹配的隐藏，本集优先，整季包与未知分开标注。判断仅为文件名依据，不承诺字幕同步准确。
- 下载整季 ZIP 时按当前季集选择，不允许默认取其他集第一份字幕。

## 范围与兼容
- 后续用户要求双端同步：字幕二级只显示三个功能，点击进入对应三级菜单并提供返回。Android 使用系统文档选择器复制到有界临时字幕文件；Exo 导入外部字幕在当前位置重新准备媒体并保留播放/暂停状态，mpv 沿用现有 URI 字幕接口。无新增存储权限。
- 无持久化格式、鉴权和播放取流变化。原有字幕轨道选择保留。

## 验收与验证
- 菜单三组可见，系统文件选择支持 SRT/ASS/SSA/VTT，取消无副作用。
- 测试单集、其他集、整季包、未知信息和 ZIP 当前集选择及缺失错误。
- 静态检查、Windows release 构建及本地部署，实际字幕显示/菜单尺寸与键盘操作待人工复核；不宣称上架就绪。

## 实现与交付
- 原生字幕面板增加三组及系统本地文件导入。先搜索片名与季集编号，未命中回退片名；优先发布文件名而非重复作品名链接，匹配结果排序、标注并隐藏明确跨集结果。
- ZIP 优先取当前集文件，缺失或多文件无法确认时拒绝自动应用。切集清空旧搜索并失效在途搜索，下载期间切集不应用到新集。
- 13 项字幕测试通过（含 ZIP 跨集优先级与缺集失败）；静态检查无错误、警告，25 项 info 中包含既有问题与当前条件格式提示。Windows release 构建通过，覆盖部署 D:\Mova，Flutter app.so 与原生播放器文件哈希核对通过，保留用户数据。
- 仅 Windows 已部署。未执行安卓构建/安装、真实字幕同步和本地文件选择器人工操作、宽窄窗口菜单视觉复核；匹配依赖来源文件名，不保证字幕时轴和片源版本一致。

## 三级菜单双端同步交付
- 两端字幕二级仅主字幕、字幕搜索、本地导入三个功能入口；轨道、结果与导入操作在对应三级菜单，提供返回字幕入口。
- Android SAF 只读取用户选择的文件，无广泛存储权限；后台复制限制 20 MB，失败清理临时文件。Exo 使用 SubtitleConfiguration 在原位置重准备并明确选中新外部轨道，可能短暂缓冲，保持原播放/暂停状态；自动字幕选择与关闭分开处理，导入错误返回面板而非误报成功。
- 27 项相关回归通过；菜单层级测试是源码接线检查，不能代替人工行为验证。静态检查无错误/警告；Windows 和 Android release 构建通过。
