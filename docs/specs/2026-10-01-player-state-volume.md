# 播放器状态与系统音量修复

Windows：关闭固定玻璃不再需要的后台视频抓取，菜单绘制图像预缩小以减少滚动重复缩放成本；弹幕有数据但刷新失败时显示已加载及刷新失败，不用失败状态掩盖现存数据。合并章节入口到片头片尾并去重，不改持久化工具键。

Android：普通 Exo/mpv 使用系统 STREAM_MUSIC 音量，播放器增益固定 unity；进入读取实际值，调节写系统值，既有定时器读回实体音量键变化。系统音量量化到设备档位。失败通道不静默改偏好，不改缓存格式。验证播放器回归、双端构建、本地部署；真实切集滚动性能与平板实体键需实测。

结果：14 项针对性测试通过，静态分析无错误/警告（19 条既有 info），Windows Release 与 Android arm64 测试 APK 构建成功。弹幕状态变化与热加载更新当前打开菜单并保留滚动位置。Windows 已部署 D:\Mova；ADB 无设备，Android 安装及真机音量/性能复测未执行。Windows 切集后滚动帧率尚未采样，不声称已确认卡顿完全消除。

部署纠正：初次 Flutter 构建的环境参数没有使测试包标识生效，安装了正式包而非用户正在运行的测试包；不能仅凭 install Success 判定目标应用更新。后用 android/gradlew assembleRelease -PmovaLocalTest=true 显式构建，aapt 核对 com.taohua.mova.debug / Mova · 测试 后安装成功，测试包更新时间 2026-10-01 20:36:36。保留数据；实际调节系统媒体音量需用户复测。
