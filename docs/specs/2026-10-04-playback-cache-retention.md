# 双端播放缓存清理

日期：2026-10-04。状态：已实现、已测试、已构建、已部署，真实播放验收待完成。影响：Windows、Android Exo/mpv。

## 背景与目标
现有弹幕保留 60 天且没有播完删除，视频仅容量淘汰，Exo 原生缓存仅 LRU。统一已播放完成（自然结束、片尾跳转、现有 92% 完成阈值、手动标记）删除视频及对应弹幕；未完成连续 7 天未使用删除。
不修改完成阈值、播放管线、缓存限额、海报缓存或用户观看记录。正在读取/下载的缓存受保护，完成清理等资源释放；Windows 文件被占用时不强删。程序关闭期间不会后台运行，到期后下次启动/缓存维护清理。

## 技术与兼容
复用现有视频/弹幕 Store，统一观看状态保存触发完成清理；启动后台清理过期缓存及既有完成记录。按实际读取/缓存下载更新最后使用时间，旧文件无字段回退文件修改时间；弹幕新增可选剧集身份，旧文件根据当前 API 配置识别、读取时补齐身份，无法识别的旧来源缓存仍按 7 天清理。不更改现有缓存键，兼容旧 JSON，回滚安全，但已删除可再下载缓存无法恢复原字节。
Exo 原生 Cache 元数据按 URL 摘要匹配所有鉴权版本，清理在后台执行，保留原生取流和 128 MiB LRU。只删除应用缓存，不删除本地导入媒体或观看历史。无敏感 URL 日志。

## 验收与风险
测试 7 天边界、重复使用续期、旧格式、完成清理及活动保护；两端 Release 构建并本地覆盖部署。清理不能阻塞启动首帧，不更改用户系统时间模拟真实过期。人工验证自然播完/片尾切集/92%退出/手动已播放、Exo/mpv、代理/本地缓存，长测仍需记录。

## 实现记录
已修改：CacheRetention 在共享观看状态 save/setPlayed/import/replaceAll 完成转换时排队删除；自然完成及片尾跳转额外接入。播放器与预加载任务用进程内引用计数保护，播放器切集或退出、下载结束后执行待清理；92% 后停止当前集持续写缓存。取消已播放标记取消待删除任务，迟到的弹幕请求不重建已完成缓存。共享缓存过期按最后使用时间；容量上限可能更早淘汰闲置内容，7 天不是保留保证。

旧弹幕补充可选 episodeKey，不更改文件名/评论/保存时间；读取续期用文件时间，不把内容刷新时间变成当前时刻。旧未识别来源弹幕、未建立 URL 摘要的旧 Exo 前缀无法凭空恢复身份，只按 7 天闲置淘汰。Exo 原生后台维护使用 Media3 ContentMetadataMutations / CacheSpan.lastTouchTimestamp；按 URL 摘要清理所有已识别鉴权版本，活动读写保护、释放后再处理。
参考：https://developer.android.com/reference/androidx/media3/datasource/cache/CacheSpan ，https://developer.android.com/reference/androidx/media3/datasource/cache/ContentMetadataMutations 。

已测试：最终 378 项完整 Flutter 回归通过；包含临时文件的 7 天边界、活动缓存保护、旧元信息续期、弹幕读后续期且不改变内容刷新时间、手动完成跨源弹幕清理、92% 完成和旧弹幕清理、撤销标记、迟到弹幕不重建；观看历史保持。旧 .bin.part 过期连带删除正确的 .json 元信息，回归通过。完成清理只读取弹幕 JSON 的最多 256 字节身份头，不反复解析整份评论，防止维护引入启动负担。静态检查无错误/警告，28 项既有 info。格式/diff 检查通过。源码接线与构建不代替 Exo 原生文件删除真机验证。

部署：用户确认双端退出后，Windows 覆盖 D:/Mova，恢复 SHA 校验的 gpu-next/libplacebo DLL；安装与构建 app.so SHA256 一致（8841E27687591C53C09D3FCC34B50FAB203FE65E7B20DE88E483A75267F0F0C9）。Android OPPO OPD2401（f9f3a649）com.taohua.mova.debug 使用 adb install -r，同包保留数据返回 Success，系统 lastUpdateTime=2026-10-04 05:20:45；版本仍 3.1.120。未直接清用户目录或主动运行新包删除缓存，策略在下次启动/播放/缓存维护生效。

未实测：真实双端完整播放/片尾跳转后的缓存释放、Exo 原生数据库实际命中及删除、持续播放长测；未修改系统时间模拟真机过期，不宣称上架合格。需要用户播放一次完成/退出、手动已播放并对照缓存，以及 Exo/mpv 两条真实路径。
缓存删除为用户明确授权策略，覆盖安装保留其他数据；不提交/推送/发布。被清理的应用缓存不是服务器或本地导入媒体，不可原字节恢复，但可重新下载。
