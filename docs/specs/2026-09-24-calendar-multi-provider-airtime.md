# 多平台播出时刻来源

## 基本信息

- 日期：2026-09-24
- 状态：首轮通用来源接入完成；平台专属来源仍待逐一核验
- 影响平台：Windows / Android（共享业务逻辑）

## 背景与目标

不同平台的节目可能在 TMDB/Trakt 只有播出日期，TVmaze 也可能缺少 IMDb/TVDB 外部 ID。日历应使用跨平台的已发布排期数据补足实际时刻，不凭播出日或服务商惯例推算。

## 数据与范围

- 已有来源：TMDB 提供日期与节目网络信息；Trakt 日历提供 `first_aired`；TVmaze 集级排期可能提供精确 `airtime/airstamp`。
- 本次先修复 TVmaze 仅靠 IMDb/TVDB 关联造成的覆盖缺口：改用精确标题别名和首播年份校验来匹配无外部 ID 的节目。
- 各流媒体服务并无统一公开排期 API；官方帮助页中的常见发布时间规则有每周剧、地区和授权差异，不能套用到具体剧集。
- 官方站点有明确排期但通用源缺时刻时，后续按用户当前待看实际平台逐个评估可用的官方 API；不抓取需登录/签名的私有接口，不硬编码单剧时间。

## 兼容与安全

- 不新增依赖、账号授权或持久化键；继续使用现有超时与 6 小时排期缓存。
- TVmaze 模糊搜索结果不直接采纳；只接受名称/别名精确匹配且首播年份不冲突的节目，避免同名误配。
- TVmaze 时间缺失或有占位时刻时维持“时刻未公布”。

## 验收标准

- [x] IMDb/TVDB ID 缺失时可用精确名称别名命中有时刻的 TVmaze 节目。
- [x] 同名/年份不符候选不采纳。
- [x] 所有平台的节目继续由统一日历合并路径消费 TVmaze 排期；不能从上游拿到的精确时间保持未知。
- [x] 全量测试、静态分析、Windows 构建和本地部署通过。

## 首轮接入结果与边界

- 外部 ID 关联仍优先；缺失时改用 TVmaze 标题搜索，再以规范化后的剧名/AKA 精确相等、首播年份不冲突和候选唯一性确认节目。精确规范名命中时不额外请求 AKA，降低当前待看列表的请求量。
- TVmaze API 的 episode list 提供真实 `airtime/airstamp` 时才补时刻；日期仍由 TMDB/Trakt 与既有合并规则负责。无时刻或占位时间继续显示未公布。
- TVmaze 官方说明其全球 Web Channel（例如全球流媒体服务）不记录发布时间；Netflix 官方也说明周更/原始播出剧可能偏离常见上线规则。因此，此首轮改进是全平台可用的公共聚合源补强，不等于每个平台都能被补出时刻。后续如要官方站点级接入，需各平台公开、稳定且可合法访问的节目排期接口；目前不依赖登录 Cookie、私有签名接口或通用时间推断。
