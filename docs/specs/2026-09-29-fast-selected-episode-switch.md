# 单集资源首响切换优化

## 基本信息

- 标题：单集资源首响切换优化
- 日期：2026-09-29
- 状态：已完成
- 影响平台：两端；Windows 原生播放器追加资源菜单热更新
- 关联 Issue、提交或版本：无

## 背景与问题

Windows 原生播放器切换到尚未搜索的集时会暂停当前视频并等待 Flutter 解析。当前解析流程等待所有服务器搜索结束，还串行等待观看进度、Trakt 状态与资源偏好计算；单个慢服务器会拖住已经找到的可播资源，造成切集长时间停顿。

## 目标

- 某个服务器找到选中集后，尽快恢复原播放器并开始播放；当前播放服务器结果优先，采用有上限的短暂等待，不因慢服务器无限阻塞。
- 其余服务器继续后台搜索，增量更新详情页资源状态及 Windows 播放器资源菜单。
- 复用当前详情页生命周期内已验证的 Emby 会话线路和 TMDB 对应剧集 ID。
- 观看进度、Trakt 完成状态和偏好计算退出切集关键路径；只按当前选中集搜索。
- 保留代次校验，快速连切时旧搜索不得覆盖新集或播放器资源列表。

## 非目标

- 本次不改硬件解码、全季聚合、观看记录格式、服务端协议或播放器重启策略。
- 不保证慢服务器能在播放器关闭后继续工作；后台补充结果仅在当前详情页/播放器会话仍有效时更新。

## 用户流程与界面

用户在播放器选取尚无播放地址的集后，播放器短暂显示搜索状态；首个优先/可用服务器命中后立即在原播放器继续播放。其他服务器随后出现在资源菜单中。无服务器命中时维持当前错误恢复逻辑。Windows 资源面板如果正打开，更新列表而不关闭面板；Android 继续使用 Flutter 播放页切集。

## 数据与接口

- 输入与输出：选中季集、当前资源来源；返回该集首个可播媒体及增量资源选项。
- 数据来源：现有 Emby/WebDAV 搜索、TMDB 编目、观看记录和 Trakt。
- 新增/修改字段：仅进程内会话/Series ID 缓存；Windows 原生 stdin 增量资源快照消息。
- 持久化键或缓存格式：无变化。
- 网络接口、超时与错误处理：复用现有接口；单个服务器失败不阻断已命中资源，全部失败仍报当前集搜索失败。
- 隐私与敏感信息：缓存只在页面内存保存；原生资源消息仅包含展示数据，不包含播放 URL、鉴权 headers 或 token。

## 技术方案

- 详情页复用现有渐进式 `publish`；加入“首个可播结果”完成信号和短暂当前源优先窗口，完整搜索仍由后台 future 执行。
- 把当前源 ID作为优先源。首个资源到达后如优先源在短窗口内返回则选它，否则选已到达的首个可播资源；窗口有严格上限。
- 当前集命中后立即返回给 Windows 原生播放器；服务器会话与系列映射在详情页内复用，避免切集重复验证和匹配。
- 完整聚合完成后在后台计算观看/Trakt 状态，并通过版本化消息更新仍在播放的集的资源面板。
- 所有异步回调按搜索代次、播放请求和目标集校验；旧结果仅忽略，不恢复/覆盖播放器。

## 兼容与迁移

- 旧版本数据继续可读；无持久化或服务端协议变化。
- Windows 使用原生增量菜单消息；Android 不使用该消息，仅复用首响/后台聚合逻辑。
- 回滚后安全；不需迁移、清理或功能开关。

## 风险与回滚

- 主要风险：后台结果与新选中集竞态、原生 stdin 消息滞后；用请求代次、目标集和资源快照版本校验。
- 监测方式：日志/探针验证消息次序、首响与全量完成边界。
- 回滚步骤：回退详情页、播放器 stdin 协议及原生消息处理改动；无数据迁移。

## 实现记录

已实现：首个可播结果由 `EpisodeSearchGate` 在当前服务器 400ms 优先窗口内决策；其他源继续并发搜索。Emby 验证线路及 TMDB Series ID 在详情页生命周期内缓存。选集元数据不再挡住播放地址解析；全量搜索结束后的线路保存、观看/Trakt 进度派生均后台执行。Flutter 播放页资源面板与 Windows 原生资源菜单都接收增量展示快照；原生消息只含来源名、规格、图标路径、标记和排序，不含 URL 或鉴权信息。Flutter 切集不再等待最多 4 秒的服务器停止上报或最多 3 秒的远端续播查询，使用已有本地/资源进度起播，停止上报在后台完成。

验证：新增的首响优先策略及原生资源快照编码测试通过；与剧集续播、全季目录相关的测试通过；`flutter analyze --no-fatal-infos --no-fatal-warnings` 通过；Windows Release 构建通过。全量测试执行 235 项后有 4 项失败，分别在已修改但与本次切集优化无关的 `detail_origin_transition_test.dart`（2 项）、`discover_scroll_virtualization_test.dart`、`glass_uniformity_test.dart`；未做基线复跑。Windows/Android 实机切换流程尚待用户验证；本次未部署。
