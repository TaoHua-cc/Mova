# Android 平板同步 Windows 更新

## 基本信息
- 日期：2026-09-30
- 状态：实现中
- 平台：Android；共享代码验证 Windows

## 差异与目标
平板 OPD2401 当前安装 3.1.114，仓库版本 3.1.116。首页、详情、观看记录、来源匹配和滚动缓存使用共享代码，更新 APK 即同步。Windows 原生播放器与 Android Flutter 纹理播放器分别实现控件，需要同步交互而保留平台解码路径。

同步合并音轨/字幕菜单、在线字幕同面板返回、即时轨道选中反馈、进度拖动本地预览并松手提交、触控面板尺寸适配。切集继续保留播放器并使用现有资源解析与缓存逻辑。

## 数据与兼容
复用现有字幕服务、PlayerEpisode、观看记录和缓存。无持久化键、网络协议或缓存格式变更。Windows 仍走 MovaNativePlayer，Android 仍走 media_kit 和专用 Dolby Vision 路径。

## 验收与验证
- 合并面板可切换真实轨道，选中立即更新，返回保留当前播放器。
- 进度拖动圆点实时跟随，松手只提交一次 seek。
- 平板横竖屏面板不越界，保留关闭按钮与可滚动内容；窄屏可操作。
- 执行格式化、静态检查、相关测试和 APK 构建；安装连接平板验证。
- 不引入虚假生产数据或泄露凭据。

## 风险和回滚
轨道列表在加载中可能变化，使用播放器实时流刷新。回滚本次 Dart 修改即可，用户数据不变。

## 实现记录
已复用共享玻璃组件增加关闭背景采样选项（默认保留其他页面行为），Android 菜单与手势 HUD 使用固定材质。音轨/字幕合并，轨道列表监听选中流，提供媒体默认与关闭字幕操作；搜索在原面板返回。进度条本地预览，松手提交。切集显示等待反馈，无资源时恢复原播放/暂停状态，异常可见且可以重试。

差异核查：3.1.114 到 3.1.116 的首页立即移除继续播放、服务器同步来源、详情缩略图选中框和边界居中、全集列表、字幕下载服务、滑动视频缓存均位于共享 lib，随 APK 更新同步。Windows 原生控件键盘导航、gpu-next 输出不直接移植到 Android；Android 专用 Dolby Vision Activity 保留 Media3 系统控件。

连接设备：OPD2401，arm64-v8a，2120×3000 / 420 dpi。原版已无损安装官方签名 3.1.116（build 2127）；本次新增功能装入独立包 com.taohua.mova.debug，名称 Mova · 测试，版本 3.1.116-debug（build 127）。本机没有正式签名密钥，测试包不覆盖原版或迁移账户。Android SDK/NDK/JDK 放在未跟踪的 .tool-home，未提交任何签名材料。

Windows Release 两次成功构建并部署 D:\Mova，最终代码已部署；Android 最终 debug APK 成功构建并安装。平板横屏发现页、竖屏首页/真实空态截图已检查，启动/旋转日志没有 RenderFlex、E/flutter 或 FATAL EXCEPTION。恢复原先自动旋转设置。

静态检查无 error/warning，18 项既有 info。全量测试 241 通过、3 项既有失败（详情上下文入口/全集玻璃源码断言和发现玻璃 grouped 断言），针对性固定玻璃/缓存进度等 17 项通过。测试版没有原账号配置，真实鉴权影片播放、切集延迟、字幕应用和硬件解码帧率尚未真机复核；debug 构建不用于性能结论。正式签名整合本次改动仍需正式发布构建。
