- 关联 Issue、提交或版本：无

## 背景与问题

详情主滚动和人物作品列表已经使用 `YingjiSmoothWheel`，但“全部剧集”弹窗没有接入它。详情返回转场每帧通过 `LayoutBuilder` 重算锚点，对全屏详情内容执行缩放和淡出。追剧日历卡片在窄宽度内容区把文字、进度、平台标识和操作挤在同一行；Trakt 已连接状态使用深色文字配透明玻璃，深背景上辨识度低。播放器任务栏图标与 Mova 应用图标完全相同，无法一眼区分。

## 目标

- 详情页及其全部剧集列表在 Windows 鼠标滚轮下使用统一的平滑滚动，移动端继续使用原生触控滚动。
- 减少详情页返回动画的逐帧布局工作，同时保留从内容卡片展开/收合的视觉关系。
- 重新安排追剧日历卡片的标题、集数、进度、播出时刻、平台和操作区，降低拥挤感。
- 提升 Trakt 连接按钮和通用选中按钮状态的亮度、文字对比度。
- 为 Windows 原生播放器制作与 Mova 母图标有关联、但带明确播放标识的专属任务栏图标，并提供图标设计预览图。

## 非目标

- 本次不改变 Trakt 授权、日历数据来源、观看进度计算或持久化格式。
- 不修改 Android 播放器图标或播放流程，不重构详情信息架构。

## 用户流程与界面

- 详情主页面、人物作品列表和“全部剧集”弹窗中的内容滚动在 Windows 平滑；Android 保持触控惯性。
- 用户返回详情页时，动画仍朝打开来源收合；来源不可用或系统禁用动画时使用轻量淡入淡出。
- 日历卡片在宽屏保持海报、内容、平台/操作三列；较窄卡片优先保障片名、集数和进度文字，适当换行或重新放置次要操作。时间未知仍显示真实状态，不伪造时刻。
- 连接态用珍珠白高亮面和深色文字，保持现有液态玻璃圆角体系；未连接态维持中性玻璃。
- Windows 播放器图标保留 Mova 的 M 标记，并叠加清晰播放符号；应用主图标不变。

## 数据与接口

- 输入与输出：现有详情列表状态、日历事件和本地播放器图标素材。
- 数据来源：TMDB / Trakt / 本地观看记录；只变更展示布局。
- 新增/修改字段：无。
- 持久化键或缓存格式：无。
- 网络接口、超时与错误处理：无变化。
- 隐私与敏感信息：无新增敏感数据。

## 技术方案

- 将 `YingjiPinnedDialog` 的可选滚动控制器连接到 `YingjiSmoothWheel`，仅在详情“全部剧集”弹窗启用。
- `MetadataDetailPage.open` 在 push 前一次性计算卡片对齐锚点，移除转场过程的 `LayoutBuilder` 重建；保留快照、淡入与轻量锚点缩放。
- 调整 `_TrackingEventCard` 窄宽度布局和进度信息留白，继续使用现有海报、平台 logo、时刻及进度真实数据。
- 调亮 `YingjiGlass` 选中态，并让文字胶囊与圆形控件共享珍珠白选中视觉。
- 从现有 Mova 图标生成单独的 Windows 播放器 ICO；将资源嵌入 `MovaNativePlayer.exe` 并由窗口类加载。生成脚本同时输出便于评审的设计预览 PNG。

## 风险与回滚

- 主要风险：高透明度选中材质可能削弱部分背景画面的透出；卡片在窄窗口下需要观察长中文片名换行策略。
- 监测方式：宽屏、窄屏、明暗海报下检查对比度与溢出；启动原生播放器检查任务栏图标。
- 回滚步骤：恢复受影响的 Flutter 页面与 `MovaNativePlayer` 资源绑定，不触碰用户数据。
