# 全局固定玻璃材质

## 基本信息

- 标题：全局固定磨砂玻璃并移除外观滑块
- 日期：2026-10-03
- 状态：已完成
- 影响平台：Windows / Android
- 关联 Issue、提交或版本：无

## 背景与问题

全局玻璃仍由外观模糊设置控制；Windows 的液态玻璃和 Android 的固定磨砂外观也不一致。用户要求恢复早期固定磨砂玻璃并移除外观滑块。

## 目标

- Windows 与 Android 使用相同的固定浓度、中性磨砂材质。
- 不读取或采样玻璃背后的页面/视频内容。
- 移除外观页玻璃浓度滑块；旧偏好保留但不再影响新版本显示。
- 原生 Windows 播放器采用相同固定浓度，玻璃表面不采集视频帧。

## 非目标

- 不改海报图片自身的预模糊、渐进模糊与背景转场。
- 不改其他外观选项、按钮图标或布局。

## 用户流程与界面

设置页外观分区显示固定材质说明，不再显示玻璃滑块。各玻璃面板和圆形控件不响应鼠标悬停或拖动改变边缘浓度。

## 数据与接口

- 输入与输出：固定浓度 30/40；旧 `yingji.appearance.glass-blur` 键留存但忽略。
- 数据来源：无外部数据。
- 新增/修改字段：不新增字段。
- 持久化键或缓存格式：不变；旧键不删除。
- 网络接口、超时与错误处理：无。
- 隐私与敏感信息：不读取背景截图或视频像素。

## 技术方案

- 共享 `YingjiGlassSurface` 取消平台分叉与交互式液态边缘，固定材质不再监听外观设置重建。
- Windows 原生播放器固定使用同一浓度，移除玻璃浓度热更新入口。
- 移除设置页滑块及其状态、持久化和应用逻辑；启动不再读取旧滑块偏好。

## 兼容与迁移

- 旧版本数据是否可继续读取：旧键保留，其他设置照常读取。
- Windows / Android 差异：玻璃浓度与材质统一；平台原生边缘绘制可保留各自实现。
- 回滚后是否安全：安全，旧版本可继续读取原有数值。
- 是否需要迁移、清理或功能开关：不需要。

## 风险与回滚

- 主要风险：固定浓度可能与用户先前自定义的浓度不同。
- 监测方式：双端查看面板、按钮与播放器菜单的可读性。
- 回滚步骤：恢复旧滑块与偏好读取即可；旧键未删除。
