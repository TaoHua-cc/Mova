- 影响：共享 Flutter Windows / Android；本次本地部署 Android，Windows 原生播放器保持既有固定材质。
- 目标：移除剩余独立 FrostSurface、榜单悬浮预览、详情资源卡的实时背板采样；保留首页海报、静态页面背景、预模糊海报和转场。
- 方案：复用 YingjiGlassSurface，统一固定材质浓度函数与外观滑杆，低白雾、现有高光、厚度渐变和细描边。选中态保留明确对比。不添加背景截图缓存或依赖。
- 兼容：不变更数据格式、持久化键、协议或版本。移除 APK 临时 glass skip 参数和帧日志，恢复正式构建。
- 验证：共享测试、静态检查、Android Release 构建；平板重新确认首页发现滚动、设置/服务器/详情/菜单可读性。Windows 未部署，人工视觉复核待执行。
