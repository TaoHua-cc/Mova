# Mova 3.1.125 双端预发布

- 用户授权推送发版，版本 3.1.125+136。推送 main 更新 Continuous，不推正式 v 标签，不标记正式上架合格。
- 内容：资源色彩范围语义排序；服务器卡片默认最高规格，选中替换后按当前显示值重排；版本菜单遵循筛选；上下集与双端预加载选择当前服务器最佳规格版本，保留原播放器引擎和手动选择。
- 发布前功能改动已通过完整 441 项测试、双端 release 构建及本地覆盖部署（本地 3.1.124+135）。本次递增版本后由 CI 重建签名发布产物，不将旧本地构建说成本次版本安装包。
- 兼容：无偏好键、缓存格式或服务端协议变更，不清理用户数据。只提交目标文件，排除临时探测、工具目录、凭据和生成物。
- 未完成：实际自动切集/多服务器选源复测、Exo 菜单流畅度、正式候选长测。最佳表示元数据规格最高，不保证所有设备与网络最佳体验。
- 发布产物目标：Windows 安装器、便携包及 Android 三架构 APK；CI 成功和五项版本产物齐全后确认预发布完成。
