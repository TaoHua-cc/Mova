# 安卓播放自动画中画

- 平台：Android；Windows 不修改、不部署。
- 播放中使用 Home 手势进入画中画；暂停、播完、退出播放页关闭自动进入。
- Android 12+ 使用系统 autoEnter；Android 8–11 使用 onUserLeaveHint。设备不支持或系统禁止时不影响播放。
- 复用现有手动画中画，不改变持久化键及播放取流；不增加权限。
- 验证：平台构建、共享静态检查；平板播放/Home/恢复/暂停/Home/退出播放器/Home 实测。未实测不声明通过。
- 已知限制：专用旧 DolbyVision Activity 不在普通共享播放页路径，本次不更改该兼容入口。
- 实现/验证：MainActivity 接收播放资格，Android 12+ setAutoEnterEnabled，8–11 onUserLeaveHint；共享 Exo/mpv 播放状态与完成/销毁清理接入。静态检查无错误/警告（21 条已有 info），现有安卓播放器 6 项测试通过，不等于自动 PiP 实机测试。首次测试命令包含不存在的 android_surface_view_test.dart 路径，已纠正后重新通过。Android release 构建通过，OPPO f9f3a649 adb install -r 返回 Success；Windows 未部署。Home 自动进入、暂停不进入、恢复和系统权限禁用仍待用户实测。双端菜单持续卡顿排查尚未完成，不包含在此修复。
