# 详情页滚动与玻璃稳定性

## 基本信息

- 标题：详情页滚动统一平滑并保持玻璃模糊
- 日期：2026-09-25
- 状态：已完成
- 影响平台：两端（桌面滚轮统一平滑；触控保留系统手势）
- 关联 Issue、提交或版本：无

## 背景与问题

详情页主纵向列表已有平滑滚轮，但季/集、资源、演职人员、艺术图、相似推荐及音轨/字幕等列表仍使用原生滚动。全部剧集弹窗在滚动时，玻璃背景模糊会消失：稳定玻璃作用域目前只包住滚动内容，没有覆盖外层弹窗材质。横向预览列表未展开时，普通鼠标纵向滚轮不应让它横移。

## 目标

- 详情页内所有可滚动纵向列表和横向货架在 Windows 桌面滚轮/触控板下使用统一平滑滚动。
- 横向预览货架只响应横向滚动手势；普通鼠标纵向滚轮继续滚动详情页纵向内容。
- Android 保持原生触控滚动与回弹。
- 全部剧集和其他接入平滑滚动的玻璃弹层在滚动过程中保持稳定材质，不闪断模糊。

## 非目标

- 本次不调整详情页的信息架构、卡片视觉、数据来源或滚动位置记忆。
- 不改变其他页面已有的滚动手感与处理规则。

## 用户流程与界面

详情页主列表、季/集/资源/演职人员/艺术图/推荐横向货架、全部集合网格、音轨字幕选择列表、资源选择等溢出列表均可平滑滚动。鼠标滚轮在横向货架上连续移动该货架；触控设备仍以原生手势滚动。宽屏、窄屏和键盘/鼠标/触控行为保持现有布局与操作。

## 数据与接口

- 输入与输出：现有列表数据与各列表自己的 `ScrollController`。
- 数据来源：不变。

## 技术方案

- 扩展现有 `YingjiSmoothWheel`，依据绑定的 `ScrollPosition` 轴向平滑处理滚轮；仅由 PointerSignalResolver 选中的嵌套滚动容器推进，避免父子列表同时移动。
- 详情页各横向货架及尚未覆盖的弹层列表复用该组件，桌面交由平滑组件处理，移动端保留原生 physics。
- 带滚动控制器的 `YingjiPinnedDialog` 将稳定玻璃作用域提升到整个弹窗，使弹窗壳体也不在滚动时关闭背板滤镜。
