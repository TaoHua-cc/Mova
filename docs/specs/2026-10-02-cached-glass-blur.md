# 缓存玻璃模糊

- 平台：Windows / Android，共享 Flutter 材质；双端本地部署。
- 问题：固定磨砂滑块增加白雾，而不是模糊背景细节。
- 目标：低且固定的白色折射色；左端近透明、轻微模糊，右端强模糊。保留高光与选中态。
- 方案：在页面/浮层出现或外观调整后，截取一张低分辨率应用内背景，排除玻璃自身及其文字，烘焙模糊并共享纹理。滚动期间不截图，不采样逐帧视频，不写截图到磁盘。缓存仅存在内存，销毁时释放。
- 取舍：背景冻结，不准确跟随后方内容变化。播放器继续使用固定材质，不承诺 Exo SurfaceView / HDR 视频截图；原生 Windows 播放器的固定材质去除随滑块增加白雾的行为。
- 兼容：保留外观偏好键及 0–40 范围，不修改用户数据、版本或协议。
- 验证：缓存排除自身、截图次数、不同模糊强度、共享材质无 BackdropFilter、静态检查、全套测试、双端构建。人工确认宽屏/平板、首页发现滚动、菜单可读性与外观端点。
- 回滚：撤销本任务缓存范围与材质接入，不清理用户数据。
