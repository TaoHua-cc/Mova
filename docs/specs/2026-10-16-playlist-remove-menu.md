# 片单影视移除菜单

- 范围：Windows 右键、Android 长按，待看海报和自定义片单条目复用已有固定玻璃菜单；仅选择移除才写入，取消不修改。
- 复用 WatchlistStore.remove 与自定义片单保存逻辑，不改持久化键。保留现有移除按钮、打开详情和排序；按作品身份而非旧位置移除，避免排序后删错条目。
- 仅移除当前片单成员，不删除服务器影片、观看记录或其他片单；网络同步规则不变。无新增依赖，不取样背景。
- 验证：真实菜单组件鼠标右键与长按、取消、一次触发回调；静态检查。宽屏/窄屏实际数据与持久化重启需人工复核。本次不提交、推送或发布。
