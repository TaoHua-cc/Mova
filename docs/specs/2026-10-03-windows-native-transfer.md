# Windows 原生取流迁移

- 日期：2026-10-03
- 状态：已实现并本地部署，待真实服务器及长时间验收
- 平台：Windows；Android 不改变

## 目标与范围

用户要求 Windows 改为原生取流。未勾选代理的服务器直接交给现有 libmpv；完整旧缓存优先本地读取。勾选代理的服务器保留本机中转以正确支持 HTTPS 代理（mpv http-proxy 官方限制不支持 HTTPS 资源）。不新增播放引擎、视觉样式或偏好键。

## 技术与行为

- 原生路径使用引擎有界内存预读，不另启当前/下一集视频下载。不声称该缓冲是跨会话持久缓存；旧缓存不清理，代理路径沿用旧缓存策略。
- 首播、已解析选集、自动连播、按需聚合选集统一生成播放地址及鉴权头；本地文件与本机代理不携带源站鉴权头，每次换集明确清除旧头。
- 子进程清除继承的 HTTP/HTTPS/ALL_PROXY 环境变量，确保未勾选服务器不会因环境变量走代理。代理路径由既有服务器路由负责，系统 VPN 不属于应用 HTTP 代理。
- 原生网络速度每秒读取 libmpv cache-speed（原生 I/O 一秒窗口统计，官方标为可能不精确），不是媒体码率或缓冲时长估算，也不是线路带宽。完整本地文件显示零网络速度；中转路径沿用实际交付字节统计。
- 保留续播、鉴权、资源切换、章节、弹幕和退出进度同步。TLS 校验不因迁移关闭。

## 兼容与风险

不更改用户数据与旧缓存格式。未勾选代理的原生播放不再写入旧持久缓存；设置容量继续作用于中转/已有缓存维护，原生使用独立有界引擎缓冲。不得宣称所有路径已原生或永久离线缓存已实现。

## 验收

- [ ] 普通/代理/完整缓存路径及鉴权头正确，重复切集不继承旧头。
- [ ] 原生路径无当前/次集重复源站下载；环境代理不改变未勾选路由。
- [ ] 每秒原生 I/O 显示、停读归零、本地读取不当网速。
- [ ] 针对性测试、完整回归、静态检查及 Windows release 构建部署。
- [ ] 同资源实际播放、拖动、切集、切服务器和退出进度保存。
- [ ] 按 QUALITY_STANDARD 完成长时间稳定性和同条件性能对照。

## 验证记录

2026-10-03：完整 Flutter 回归 345 项通过；随后新增完整旧缓存复用用例，原生取流专项 5 项通过。Windows release 构建成功，已保留用户数据覆盖部署到 D:\Mova，安装的 app.so 与原生播放器文件哈希和构建产物一致。Android 不构建、不部署。

实际 libmpv 本地 HTTP 探针通过播放、Range 拖动、换文件清除鉴权及原生 I/O 速度读取：5 次请求、5 次 Range，请求鉴权无误，最大读取速度 2030702 字节/秒。该探针不代替真实服务器、视频画面、HTTPS、完整 UI 与长时间稳定性验收。

已知限制：Windows 设置中视频缓存容量的旧说明尚未区分原生内存预读与代理持久缓存，以本规格行为为准。真实服务器播放、切集、退出同步与长测仍待确认。回退仅恢复本次取流选择和统计修改，不覆盖其他用户工作。
