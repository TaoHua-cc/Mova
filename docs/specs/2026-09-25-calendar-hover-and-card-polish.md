# 追剧日历卡片与交互反馈优化

## 基本信息

- 标题：追剧日历卡片与交互反馈优化
- 日期：2026-09-25
- 状态：已完成
- 影响平台：Windows / Android
- 关联 Issue、提交或版本：无

## 背景与问题

追剧日历卡片内侧留白导致海报不能贴齐卡片左边；卡片和日期选择项缺少一致的桌面悬浮与按压反馈；进度条的计数与轨道视觉层次较弱。Trakt 已连接态在窄布局及半透明背景上辨识度不足。

## 目标

- 海报贴齐卡片左侧并铺满卡片高度，保留卡片外圆角裁切。
- 日历卡片和日期项有不改变布局的悬浮强调，以及按压/抬手回弹。
- 进度条清楚表达已看、未看、总集，并加强已看端的视觉层次。
- Trakt 已连接态更醒目且可读，连接状态仍与共享凭据状态同步。
- 共用按钮、可点击表面使用同一组 Mova 动效时长与曲线。

## 非目标

- 本次不修改 Trakt 接口、同步规则、持久化格式或剧集进度数据来源。
- 不重构所有业务页面，也不更改点击行为或触控滚动行为。

## 用户流程与界面

日历卡片在鼠标悬停时以描边/阴影强调；按下时轻压，抬手回弹。触控端保留按压反馈但无悬浮态。海报与卡片左缘、上下缘齐平并受外圆角裁切。卡片进度展示计数与层叠轨道。Trakt 连接胶囊在已连接时使用清晰的珍珠白选中面及可辨识的状态标记。

宽屏与窄屏均检查标题、进度及右侧平台/操作区不溢出；Windows 鼠标/键盘焦点与 Android 触控保持可用。

## 数据与接口

- 输入与输出：既有 Trakt 连接状态、播出事件和本地/Trakt 进度，只改变呈现。
- 数据来源：既有本地播放记录、Trakt 观看进度和播出安排。
- 新增/修改字段：无。
- 持久化键或缓存格式：无。
- 网络接口、超时与错误处理：无改动。
- 隐私与敏感信息：不涉及。

## 技术方案

- 在 `lib/src/brand.dart` 对齐共用表面、图标按钮和胶囊按钮的按压/回弹令牌；避免悬浮缩放大型玻璃卡片导致边缘抖动。
- 在 `lib/src/media_center.dart` 收紧日历卡片海报布局，复用共享交互表面，强化进度条层级和 Trakt 连接态。
- 增加针对动效共享约束和日历卡片结构的回归测试。
