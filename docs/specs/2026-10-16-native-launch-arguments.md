# Windows 长剧集启动参数修复

- 根因：全部剧集及资源元数据直接传给 Process.start，超过 Windows 命令行上限；ProcessException 被原样展示，可暴露媒体地址和鉴权。
- 方案：完整参数按 UTF-8 百分号转义逐行写入独立随机临时目录，只在命令行传参数文件路径；原生有限读取后使用现有解析器，不更改播放、切集、鉴权或预加载策略。旧命令行调用保持兼容。
- 生命周期：原生读取后删除文件，Flutter finally 删除自己的临时目录，启动失败也清理。不记录文件内容，错误仅显示安全系统错误码。异常断电遗留文件风险保留，使用用户临时目录，不写共享可预测文件。
- 验证：长列表超过32K、中文/换行/转义字符往返、启动失败提示不含参数、原生与Dart构建；实际长剧集播放需复核。
- 本次不自动提交推送或发布，不覆盖其他片单与界面改动。
