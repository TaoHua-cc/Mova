# Android 播放控件、追剧日历与二级菜单滚动

## 基本信息

- 标题：Android 播放器旋转与画中画、日历重复事件和菜单滚动性能
- 日期：2026-10-01
- 状态：已完成
- 影响平台：Android；共享日历与滚动材质组件需回归 Windows
- 关联 Issue、提交或版本：无

## 背景与问题

- Android 播放器右上角当前提供沉浸式全屏按钮；用户希望移除它，改为旋转与画中画入口。
- 追剧日历 10 月 4 日的《兰香如故》出现多条记录，需要区分真实不同剧集与多个数据源的重复事件。
- 二级菜单上下滚动掉帧。项目已有统一滚动状态和玻璃表面开关，但需检查嵌套滚动状态竞争、未接入统一容器的滚动视图及滚动期间仍活跃的昂贵材质。

## 目标

- Android 播放器移除顶栏全屏按钮，提供设备方向切换和 PiP 操作；播放页原有自动沉浸式行为保持不变。
- 日历合并同一播出事件的多源副本，同时保留同日不同集、不同播出时间的合法事件。
- 为二级菜单的滚动状态建立可靠的共同路径，并根据代码/设备帧耗时证据减少滚动期间的昂贵绘制。

## 非目标

- 不改变 Windows 播放器按钮或桌面全屏快捷键。
- 不改变日历服务端接口、Trakt 同步关系、偏好键或既有持久化格式。
- 不做全局列表重构或与滚动卡顿无关的材质重绘。

## 用户流程与界面

- Android 播放器右上角保留标题和网络状态，操作按钮改为“旋转屏幕”和“画中画”；不再显示全屏切换按钮。
- 方向按钮在竖屏与横屏间切换；离开播放器仍恢复竖屏和系统栏。
- PiP 不受支持或系统拒绝时保持播放器原状，并提供可理解的失败反馈。
- 追剧日历同一日期只去重同一剧集/播出场次，不吞并该剧当日的其他集数。
- 检查平板触控滚动及桌面鼠标/键盘滚动的菜单状态；菜单背板模糊在滚动中持续启用，手势开始/结束不切换滤镜。

## 数据与接口

- 输入与输出：TMDB、Trakt 与本地待看列表生成的 `TraktEvent`，合并为日历显示列表。
- 数据来源：现有日历缓存与网络接口；只检查指定剧名/日期所需的摘要数据。
- 新增/修改字段：无预期。
- 持久化键或缓存格式：不变。
- 网络接口、超时与错误处理：不变。
- 隐私与敏感信息：诊断输出不得包含播放 URL、授权令牌或原始共享偏好文件。

## 技术方案

- `player_page.dart` 复用现有 `YingjiMotionIconButton`，调用 Android 平台桥接切换方向及进入系统 PiP。
- Android Manifest 声明 PiP 支持与必要配置变更；原生 Exo / Flutter Exo Surface 播放生命周期均需维持现状。
- `calendar_events.dart` 的去重键以节目身份、可验证集数和播出日期/时间构成；增加同日多集与多源重复回归用例。
- 盘点 `YingjiSmoothWheel`、`yingjiScrollInProgress`、`YingjiGlassSurface` 及其他二级菜单滚动组件；修正滚动状态协调并只对证实的共享瓶颈做最小修改。

## 兼容与迁移

- 旧版本缓存继续读取，不做迁移；只在当前合并阶段规范显示。
- Windows 维持当前鼠标平滑滚动、全屏和播放器界面行为。
- Android 低于 API 26 或设备不支持 PiP 时安全降级。
- 回滚为恢复 Dart/Android 源码，不需要清理用户数据。

## 风险与回滚

- 主要风险：方向锁定与设备自动旋转/横竖屏播放器期望冲突；不同设备的 PiP 策略有差异；日历数据源的剧集编号体系不同。
- 监测方式：Android 人工检查方向/PiP；用回归用例验证多源事件合并与不同集保留；在设备上采样滚动帧耗时。
- 回滚步骤：还原本规格范围内的代码改动，缓存兼容无需额外处理。

## 实现记录

- Android 播放器顶栏以方向切换和 PiP 替换全屏按钮；MainActivity 暴露 PiP 方法通道并在清单开启 PiP。平板报告支持 PiP 功能。
- 日历事件合并现在会解析中英剧集编号；当一侧缺少季数时要求播出日期一致，且明确保留不同季的同号剧集。原安装不可调试，无法安全读取其本地事件缓存，所以具体 10 月 4 日行数据未直接抽取。
- `YingjiStableScrollGlass` 现在观察其子树全部滚动通知并按 Scrollable 上下文配对活动；稳定玻璃范围跨平台有效，菜单背板滚动时持续模糊，不再让玻璃层随每次手势开始/结束切换。播放器左侧控件间距同步为与右侧相同的 4px。
- 定向日历与滚动测试通过；针对性 Flutter 分析通过（现存 info 提示）；完整分析另被仓库中原有 `test/android_player_test.dart:121` 的 `use_of_void_result` 阻断。
- Android arm64 release 本地测试 APK（包名 `com.taohua.mova.debug`）已成功构建并覆盖安装到 OPD2401，保留原应用数据并重新启动。播放器内控件与帧率需用户现场检查。
- 后续复查定位到 Android 滚动停顿的触发点是 ScrollStart/End 同步切换大量玻璃滤镜；稳定范围现跨平台生效，弹层恢复常开背板模糊。左下播放器按钮间距由 8px 收至与右侧一致的 4px。相关 15 项定向测试通过并再次本地部署；设备实际菜单滚动仍待用户复核。
