# 双端播放上架前整改

## 基本信息

- 日期：2026-10-03
- 状态：实现中，未通过上架验收
- 平台：Windows、Android

## 背景与目标

Android Exo 原生取流已接入，但原生持久缓存未接入，代理服务器仍经 Dart 中转；Windows 使用持久缓存中转。不能根据读取速度数字证明稳定播放。目标是减少取流等待及重复请求，保证切集、拖动、鉴权、路由、观看记录与恢复行为，并用真机验证。

## 非目标

不改视觉风格，不推送、打 tag 或发版，不清理现有用户缓存，不承诺所有源站或设备均支持 HDR/Dolby Vision。

## 技术方案与分阶段交付

1. 核对现有路径，减少 Exo 高频状态中的重复音轨生成、序列化和传输，保持位置状态实时更新。
2. Android 接入 Media3 原生持久缓存。先解决缓存容量、移动数据禁用、清理入口、完成删除、鉴权资源隔离及旧缓存共存，不能仅添加 SimpleCache 后宣称完成。
3. 原生取流路由遵守每服务器直连/代理设置；HTTP 兼容策略须先取得明确安全选择。不得绕过之前拒绝的安装操作。
4. Windows 原生取流与当前中转同资源、同网络、同缓存条件对照。切集必须同时更新鉴权头和服务器路由；完成速度统计后再迁移默认路径。
5. 统一网络读取与本地缓存命中统计口径，避免把磁盘交付当作外网速度。验收播放错误分类、有限恢复、进度保存和服务器同步。

## 数据、兼容与隐私

现有偏好键、缓存及观看记录保留；任何新缓存格式必须说明旧版本回退和容量共存。日志不含媒体 URL、鉴权头、Token 或凭据。测试使用本地受控响应。新增原生事件字段必须兼容既有事件解析和重建后的初始音轨状态。

## 验收标准

- [ ] HTTP、HTTPS、重定向、鉴权、支持/不支持 Range 均有明确成功或可恢复失败路径。
- [ ] 直连、服务器代理、完整本地缓存、部分缓存和无缓存分别验证。
- [ ] 开播、暂停恢复、拖动、切集、切服务器及后台恢复无错误音轨/进度继承。
- [ ] 原生缓存上限、计量网络、清理和旧缓存兼容有自动化及真机验证。
- [ ] 同资源双端记录首帧时间、缓冲次数/时长、真实网络读取和缓存命中，不用峰值速度作为唯一结果。
- [ ] 真实资源至少连续播放 30 分钟；仅证明采样期间行为，不保证任意外部服务器性能。
- [ ] 首页/发现滚动、菜单滚动、播放器进出有 profile/release 帧耗时基线及改前改后对照。
- [ ] 宽屏鼠标、平板触控、两端构建及回归通过后才判定完成。

## 风险与恢复

当前待部署 Android 网络安全配置允许任意 HTTP 地址，这扩大明文通信范围，安装曾被审核拒绝。须用户明确同意，或选择 HTTPS 原生、HTTP 保留中转的兼容范围，再继续部署。不能把该变更记录为已安装。

### HTTP 安全授权与部署（2026-10-03）

用户在获知任意 HTTP 地址会明文传输、HTTPS 证书校验仍保留后明确回复“允许http地址”。此前安装拒绝的授权条件已补齐，未绕过审核。核对本次 APK 包名为 com.taohua.mova.debug、界面名称 Mova；资源表中的 network_security_config 确认为 cleartextTrafficPermitted=true，保留 system/user trust anchors。HTTP、音轨状态、原生取流与速度显示 4 项针对性回归通过。adb install -r 成功覆盖连接的 OPPO 平板，未清理用户数据、未更新 Windows、未推送或发布。之前失败的 HTTP 服务器资源实播及长时间稳定性仍待验证。

第一阶段：Exo 音轨列表仅在变化/事件订阅时生成和发送，普通位置事件省略音轨字段；Flutter 缺少该字段时保持当前音轨，切集重置签名以恢复相同结构的音轨。位置更新频率保持 250 ms。采用现有状态通道，不增加依赖。
