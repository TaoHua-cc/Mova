# 双端播放标记与读取速度状态

- 日期：2026-10-03
- 状态：已修改、测试、双端构建部署；待用户真机复核
- 平台：Windows / Android

## 问题与目标

详情页标记未播放删除本地行后，会回退旧服务器进度；完成状态也会被旧资源状态覆盖。改为保存明确零进度，按同作品季集统一覆盖已有版本记录，先本地持久化并通知页面，再同步服务器。旧 JSON 字段和偏好键保持兼容，不清理用户缓存。远端同步失败保留本地选择。

右上角保持每秒当前资源真实读取速度，补充缓冲/充足/本地状态与实际前向缓冲秒数。Windows libmpv I/O 一秒统计可能不可用，不用码率伪造；Android Exo 使用 TransferListener 字节计数。不会读取整机其他应用流量、不增加带宽测试或重复下载。

## 验收与验证

- 标记已播放即时完成；标记未播放立即归零，重复打开仍归零，同集多资源一致。
- 旧服务器/Trakt 快照不覆盖最新本地选择；新播放可以正常推进。
- 数值每秒更新，零速不误称网络断开；窄屏不挤压窗口按钮。
- 单元测试覆盖持久化、别名、多集隔离与刷新优先级；双端构建部署保留数据。
- 真机人工路径：详情预览/全部集列表反复标记、返回继续播放；播放、暂停、拖动时查看速度与缓冲状态。

## 风险与记录

只修改当前状态和显示，不改变取流路由。零进度行遵守已有记录容量，未来来自其他设备的更新仍可同步。实际部署、测试与人工复核完成后填写；不以构建代替上架播放长测。
