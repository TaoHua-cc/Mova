# 固定统一磨砂玻璃

日期：2026-10-03。影响：Windows 与 Android。状态：实现中。
实现记录：公共 UI 的取样与截图缓存路径已移除，旧缓存模块及其取样测试已删除并替换为无取样回归。保留透明叠加，不承诺背景颜色完全不可见。全量 327 项测试通过，最后手势材质补齐后另有 5 项定向测试通过；静态检查 20 条既有 info，无错误/警告。Windows Release、Android 本地测试包构建成功。平板覆盖安装成功且保留数据。真实菜单观感、窄屏布局、100/150/200% DPI 与设备帧率仍待人工复核。

## 问题与目标
右键菜单使用缓存页面截图，打开后缓存更新导致材质变色，与不取样背景的要求不一致。所有 UI 玻璃取消实时与缓存背景取样，保留统一中性底材、柔和反光、细边、选中反馈。播放器与自动跳过复用同一固定材质。不把提高白雾浓度称作模糊。

## 方案与边界
公共 YingjiGlassSurface 删除 BackdropFilter 和 CachedGlassSurface 路径；应用移除 FixedGlassScene 装配与路由刷新；HUD 删除背板滤镜。保留原有 API 参数以兼容调用方，但 sampleBackdrop 不再启用取样。外观参数控制固定反光的柔化范围，不获取画面。海报自身 ImageFiltered 渐进模糊属于内容图像，不是玻璃背景采样，保留。

Windows 原生播放器固定底材与反光参数对齐，自动跳过继续复用菜单材质与统一字体。数据、配置键与网络协议不变，无迁移。回滚安全。

## 验收与验证
- 所有 UI 玻璃无 BackdropFilter、页面截图取样、视频取样。
- 菜单打开不因缓存刷新突然变色；透明叠加仍会视觉透出后方颜色，这不等于背景取样。
- 回归测试覆盖显式 sampleBackdrop=true、圆形按钮、矩形菜单和播放器 HUD。
- 双端构建、静态检查、全套测试；真机手动复核菜单与滑动、外观端点。
