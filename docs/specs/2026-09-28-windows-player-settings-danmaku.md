# Windows 播放器设置与弹幕体验修复

## 基本信息

- 标题：Windows 播放器设置、弹幕与高分屏体验修复
- 日期：2026-09-28
- 状态：已完成（待人工播放场景确认）
- 影响平台：Windows（共享设置读取路径时兼顾 Android）
- 关联 Issue、提交或版本：无

## 背景与问题

播放器启动时偶发白边；高分辨率显示器上原生播放器控件偏小。播放弹幕时打开播放器菜单会同时影响画面和弹幕流畅度。设置页的弹幕开关/API 更改以及其它播放器设置偶尔没有同步到当前会话；服务器移除后偶尔仍显示。弹幕密集时可能出现重叠、成批同时进入或过多绘制。

## 目标

- 降低原生播放器启动时可见的系统边框/白色闪烁。
- 让控件缩放兼顾窗口尺寸和当前显示器 DPI，并响应跨显示器移动。
- 保证弹幕开关/API/样式设置可靠保存并热应用；每集最多载入 1000 条，并限制同时活跃的弹幕和无效绘制。
- 保持滚动弹幕从画面右侧之外进入，禁止轨道拥堵时挤成一排。
- 服务器删除后以持久化结果刷新界面，失败时给出明确反馈。

## 非目标

- 不改变已有设置键、媒体服务器协议或播放器架构。
- 不改变 Android 视频使用 Flutter 纹理的路径。
- 不加入演示数据，也不对未在本机实际复现的显示设备效果作保证。

## 用户流程与界面

- 设置页保存的弹幕配置在当前 Windows 播放器立即生效；若播放器未运行，下次启动读取持久化配置。
- 播放器菜单打开时弹幕调度保持有界，视频持续播放；菜单关闭后弹幕继续。
- 宽屏、高 DPI 与跨显示器时控件均保持可读且命中区域一致；窄窗口控件按空间收缩。
- 服务器确认移除后从当前列表消失；存储失败时保留条目并提示原因。

## 数据与接口

- 持久化键：复用 `yingji.player.*` 与 `yingji.danmaku.*`，无格式变化。
- 原生进程热更新：复用现有 stdin `MOVA_APPLY` 消息。
- 来源列表：复用现有 `yingji.sources` 与 `SourceStore`。

## 技术方案

- Flutter 设置页确保全部依赖 `SharedPreferences` 的播放偏好写入后，向当前原生会话发送相应热更新；弹幕开关/API 改动触发当前剧集重新读取。
- Windows 原生播放器依据客户区和显示器 DPI 推导统一 UI 比例；处理 `WM_DPICHANGED` 并在显示器切换后重排覆盖层。
- API 与本机缓存读取限制为 1000 条并按播放时间排序；原生解析也设 1000 条上限，入场按 100ms 间隔错开；同时限制 live 条目和无效重绘，弹幕从播放位置之后进入。
- 玻璃背板平时更新为 30 Hz；空间菜单打开时更新一帧后暂停整窗 `PrintWindow` 和 CPU 模糊，避免持续抢占视频/弹幕的帧时间。
- `SourceStore.remove` 保证删除服务器、凭据及缓存统计的完成/失败语义，调用方据持久化列表刷新并显示错误。
- 启动窗体在视频首帧与原生 UI 准备好前保持不透明黑底，避免系统边框短暂透出。

## 风险与回滚

- 主要风险：原生多层透明窗口的 DPI 重排可能带来位置回归；弹幕上限过低会使极密集弹幕被丢弃。
- 回滚步骤：回滚本规格关联的原生播放器和 Dart 设置逻辑改动即可；持久化数据无需回滚。

## 实现记录

- 设置页弹幕 API/名称/token 编辑、增删 API 原先未触发保存；现已保存，并在设置页重载前等待待处理写入，写入失败会提示。热更新推送现在等待完成，API 名称变化也触发弹幕刷新。
- 服务器来源列表的异步修改已串行；后台探测通过“只更新已存在项”避免覆盖并发删除，统计缓存不再为已移除服务器重建；删除失败会反馈且仍按磁盘数据刷新 UI。
- 原生播放器启动时提前设置 DWM 边框颜色并显式擦黑；新增 Per-Monitor V2 的 DPI 变化处理，控件缩放上限从 1.25 调到 1.6。
- 弹幕空闲时跳过不必要的全层重绘；设置同屏 32 条上限、每帧最多新增 4 条，首次载入不回放历史弹幕，并从画面右侧外进入。
- 玻璃背板刷新从每 16ms 放宽到每 33ms，优先保持视频/弹幕的帧时间。
- 后续体验修正：API、旧缓存与 Windows 原生加载均限制到每集 10000 条并按时间排序；滚动弹幕按 100ms 间隔调度，Android 列表按时间排序后提前停止扫描未到时评论。空间菜单打开时只更新一次背板，随后暂停后台整窗采集和模糊，菜单关闭后自动恢复。
- 已部署到 `D:\Mova`；构建版与安装目录中的 `mova.exe`、`MovaNativePlayer.exe`、`libmpv-2.dll` SHA-256 均一致。
- 多分辨率/播放实机验收仍待人工完成；未运行自动化测试。
