# 全局方圆体替换规格

## 目标

将 Mova 的 Windows 与 Android Flutter 界面以及 Windows 原生播放器统一为一套方中带圆、适合小字号 UI 的简体中文字体。

## 字体选择

- 使用阿里妈妈方圆体 VF 1.000，字体内部制造商为 Alibaba Design。
- 字体包含 `wght` 与 `BEVL` 双轴，方圆切角轴默认值为最大值 100，视觉上具有明确的方圆特征。
- 字体约有 3,148 个字形；继续内置 Noto Sans SC，但仅用于罕见字缺字回退。
- 不采用 Resource Han Rounded：虽然为圆角思源系字体，但实机观感仍过于接近普通黑体，不符合用户指定方向。
- 不采用得意黑：单字重且整体倾斜，更适合展示标题而非全局正文。

## 实现

- 保留 Flutter 现有 `YingjiRound` 逻辑字体名，只替换其字体资源，使现有全局 Theme 和页面样式整体生效。
- Windows 原生播放器启动时以 `FR_PRIVATE` 注册安装目录中的阿里妈妈方圆体，并用于标题、时间、面板和状态文本。
- GDI+ 无法可靠加载该双轴可变字体，因此原生播放器使用由同一字体生成的静态实例（`wght=600`、`BEVL=100`）；Flutter 界面继续使用可变字体。
- 系统字体仅作为字体加载失败或缺字时的回退，不修改持久化数据和网络协议。

## 兼容与验证

- Windows / Android 共用 Flutter 字体资源，两端均需验证正文、标题、数字和中英文混排。
- Windows 原生播放器需验证季集标题、时间数字和设置面板。
- 方圆体约 7.4 MB；加上缺字回退字体后，字体资源合计约 25.2 MB。
- 执行 Dart 静态分析、Windows 原生 `/W4 /WX` 编译、Windows Release 构建和相关 Flutter 测试。
