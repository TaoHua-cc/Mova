# 电影系列集合

## 范围与目标
- Windows/Android 共用详情页新增系列电影横向栏目。进入任意系列电影，可查看并进入同系列每一部的详情。
- 数据只使用 TMDB belongs_to_collection 与 collection/{id}；不按片名猜系列，不表示服务器均有可播放资源。
- 复用现有海报、悬浮、拖动和详情入口，当前影片注明当前。只显示真实多部系列，非系列不增加空栏目。

## 方案与兼容
- 后续交互（用户确认）：系列卡片只切换当前详情 route 的内容，不 push 新详情页；通过影片 key 重建原有内容状态，避免旧资源/音轨串到下一部。返回一次仍回原入口。切换后回到详情顶部。
- 再次调整（用户反馈整页重载割裂）：取消影片 key 重建，保留详情 State、滚动控制器、系列列表及列表位置；didUpdateWidget 只更新影片相关 future/资源与收藏状态。资源请求使用代次隔离，迟到结果不覆盖新影片；背景清晰图片加载新 URL 时保留旧图，演员资料加载期间不替换整块内容为加载条。切换保持当前滚动位置。
- Extras 增加可选系列身份；独立异步集合请求，避免阻塞演员、艺术图与资源搜索。失败单独显示重试。
- 沿用 TMDB 网络代理和持久化响应缓存，集合使用 6 小时缓存复用；无新偏好键/格式迁移。旧 extras 无字段等同非系列。
- 按上映日期排序，未知日期放最后，同 ID 去重；保留尚未上映作品并标注年份，不虚构海报。
- 不新增依赖，不改变播放管线。失败不影响其他详情信息。

## 验收与验证计划
- MockClient 测试集合归属、排序去重、空集、无归属及失败；格式化和静态检查。
- 双端宽窄布局、鼠标/触控横向拖动、键盘操作、进入另一部、返回；普通电影/剧集不显示系列栏目。
- 人工对照《惊声尖笑》任意部；缓存冷热进入详情和返回三次，检查滚动与加载稳定性。
- 构建/部署/真机结果分开记录；未做长测不宣称上架合格。
