# 剧集预览图服务器回退

## 基本信息

- 标题：详情页剧集预览图按播出状态回退
- 日期：2026-10-23
- 状态：实现中
- 影响平台：Windows / Android（共享详情页）
- 关联 Issue、提交或版本：无

## 背景与问题

详情页存在 TMDB 剧集目录时使用目录预览栏。目录、资源与“全部剧集”列表需要在有已播出单集图时显示集图；尚未更新/播出或没有集图时，使用作品预览图而不是系列主图或空占位。

## 目标

- 已播出且存在集预览图时显示该集图片。
- 未播出或没有集图时显示作品 backdrop，backdrop 不可用时显示 poster。
- 已播出集图加载失败时尝试服务器独立集图，再回退作品 backdrop/poster；全部失败才显示占位图。
- 主预览栏、资源栏和“全部剧集”列表使用相同规则。
- 获取服务器剧照目录不触发逐集资源聚合、不阻塞播放资源搜索，遵守每服务器代理设置。

## 非目标

- 不修改 TMDB 与媒体服务器的匹配规则、播放资源聚合、持久化格式或缓存键。
- 不保证媒体服务器未提供的图片可被生成或补齐。

## 用户流程与界面

详情页剧集卡片优先显示已播出集图；未来播出日期的集不显示集图。未播出或无集图时显示作品 backdrop/poster；集图加载失败时可回退到服务器独立集图，最后保留原占位图。Windows 与 Android 共用规则，布局不变。

## 数据与接口

- 输入与输出：剧集 TMDB ID、服务器 Series ID、季号；返回该季各集的服务器图片 URL。
- 数据来源：已连接 Emby / Jellyfin 服务器剧集目录，仅请求集号与单集自身图片标签，不把系列主图误作集预览图。
- 新增/修改字段：无持久化字段。
- 持久化键或缓存格式：不变；图片复用现有 `CachedNetworkImage` 缓存。
- 网络接口、超时与错误处理：读取 Shows/{series}/Episodes 的指定季剧集目录；使用既有服务器代理路由；失败不影响播放与详情页，只保留已有 TMDB 图或占位图。
- 隐私与敏感信息：请求凭据沿用既有认证方式，不新增日志或外传。

## 技术方案

- 在 Emby 客户端新增轻量的指定季图片目录读取，避免读取媒体流版本信息。
- 详情状态按剧集、服务器、Series ID、季号去重并行获取图片目录；仅记录单集自身图片。
- 有未来播出日期时跳过集图；其余情况按 TMDB 集图 → 服务器单集图 → 作品 backdrop → poster → 占位图处理加载失败。
- 复用现有缓存图片组件和占位图。

- 主要风险：某些服务器只提供系列主图而没有单集图；此时依照规则显示作品 backdrop/poster。

- 回滚步骤：移除详情页图片目录调用和回退，旧数据无需迁移。
