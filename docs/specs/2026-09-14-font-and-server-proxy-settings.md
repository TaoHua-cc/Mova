# 字体与服务器代理设置简化

## 基本信息

- 标题：固定圆润字体并重做服务器代理选择
- 日期：2026-09-14
- 状态：已完成
- 影响平台：Windows / Android
- 关联 Issue、提交或版本：无

## 背景与问题

外观页提供多套全局字体，但产品只需要当前的圆润无衬线字体。代理页以普通开关行展示服务器，服务器辨识度和选中反馈不足，且说明没有清楚区分直连与跟随系统代理两种状态。

## 目标

- 删除全局字体设置，只保留并固定使用内置圆润字体。
- 未选中的媒体服务器直连，选中后其软件内请求跟随系统代理。
- 已连接服务器以带图标、名称和明确状态的卡片显示。
- 点击卡片选中，再次点击同一卡片取消选中。

## 非目标

- 本次不新增手动代理地址、端口或认证配置。
- 本次不修改服务器凭据、连接协议和播放器内核。

## 用户流程与界面

用户进入“设置 → 代理”，阅读简短的状态说明后点击任一已连接服务器卡片。未选中卡片标记为“直连”；选中卡片高亮并标记为“系统代理”。再次点击已选卡片恢复直连。宽屏自动并排，窄屏自动换行；鼠标、触控、键盘与读屏均可操作。

## 数据与接口

- 数据来源：`SourceStore` 中用户真实添加的服务器。
- 持久化键：继续使用 `yingji.proxy.servers`，不改变格式。
- 网络行为：继续复用 `ProxyRouting`；未选中创建直连客户端，选中创建读取系统代理的客户端。
- 隐私：卡片不展示令牌、密码或完整认证信息。

## 技术方案

- 将字体族固定为 `YingjiRound`，移除字体偏好读取、保存和外观下拉框。
- 从 Flutter 字体资源中移除文楷，只保留圆润字体文件。
- 复用 `ServerMark` 渲染服务器图标，新增可切换的代理服务器卡片。
- 保留旧代理偏好兼容；旧字体偏好会被安全忽略。

## 兼容与迁移

- 旧版本代理选择继续读取，无需迁移。
- 旧字体键可以留在用户偏好中，但新版本不再读取或写入。
- Windows 与 Android 使用相同交互；“系统代理”由各平台现有网络实现解析。
- 回滚安全，不修改服务器数据结构。
