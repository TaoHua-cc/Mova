# Windows 原生播放器视觉与设置一致性

## 基本信息

- 标题：Windows 原生播放器字体、控件面板与设置生效一致性
- 日期：2026-09-16
- 状态：实现中
- 影响平台：Windows（原生播放器）；Android 保持现有 Flutter 播放页

## 背景与问题

- 截图表明 Windows 原生播放器左上季集文字仍回退为系统字体；此前的私有字体注册并未保证 GDI+ 实际选中该字体。
- 原生播放器的底部工具岛及上拉菜单使用独立的圆形控件/列表样式，与 Mova 的石墨卡片、圆角层级和主页导航语言不一致。
- 设置页写入的播放器偏好只有“预加载下一集”被原生启动器读取；播放速度、声画延迟、画面比例、音频输出、语言、缓存、硬件解码和 HDR 等设置没有完整传递给 Windows 原生 mpv。
- 顶部的剧集组被限制在中间固定宽度，窗口缩放时没有保持左、右两组分别贴边；原生窗口没有展示实际缓存传输速率。长菜单也没有可滚动区域。

## 目标

- 原生播放器从私有 `PrivateFontCollection` 获取方圆体的实际 `FontFamily`，不以同名系统字体查找作为唯一途径。
- 使用与 Mova 页面一致的石墨卡片、14px 量级圆角、细边框和蓝色状态点重绘原生弹层与控制分组。
- Windows 启动参数映射现有 `yingji.player.*` 偏好；启动后原生面板的选择同步作用于 mpv。
- 顶部信息和窗口操作组随窗口两端锚定，网络速率采用真实缓存接收字节增量；长菜单支持滚轮、方向键和翻页滚动。
- 已保存的播放器快捷键须覆盖原生默认键位并使用设置中的快进和音量步长。

## 非目标

- 不改变 Android 播放页视觉或新增全局设置键。
- 不虚构无实际 mpv 支持的功能；无法映射的偏好应在原生面板中不显示为可用功能。

## 数据与接口

- 输入：既有 `SharedPreferences` 的 `yingji.player.*` 键。
- 输出：既有 mpv 启动参数与运行时属性。
- 持久化/网络：不新增键、不新增网络请求。

## 技术方案

- `windows_native_player.dart` 读取并传递硬件解码、HDR、速度、音频/字幕延迟、缓存秒数、比例、音频输出与语言优先级。
- 原生代码通过 `PrivateFontCollection::AddFontFile` 和实际枚举到的 `FontFamily` 创建所有文本字体；静态方圆体只用于原生播放器。
- 原生面板使用分组标题、选中行、勾选状态和页面同源石墨材质；播放比例菜单读取当前 mpv 属性决定选中状态。
- Flutter 启动器以 `MOVA_NETWORK` 管道消息传递视频缓存的真实瞬时速率；原生顶部仅展示该消息，未产生缓存时展示“—”。
- 原生启动器将快捷键偏好规范化为可识别的 Windows 虚拟键后传入；原生窗口将按键动作映射为暂停、快进/快退、音量、静音、全屏和退出。

## 兼容与迁移

- 旧设置继续读取，无迁移。
- Windows 使用原生实现；Android 不变。
- 回滚安全：删除新增启动参数与原生绘制代码即可，偏好数据不受影响。

## 风险与回滚

- 主要风险：GDI+ 对私有字体族和部分 mpv 属性的支持差异。
- 监测：启动后读取 mpv 当前属性，字体以实际私有字体族绘制。
- 回滚：恢复原生字体/面板绘制和启动参数；现有设置保留。

## 实现记录

- 原生播放器不再用字体名称直接构造 GDI+ 字体；启动时读取打包的静态方圆体，通过 `PrivateFontCollection` 枚举实际字体族，再为所有原生文字创建字体，避免系统回退。
- Windows 启动器已映射硬解、HDR、速度、声画延迟、预读缓存、比例、下混、语言偏好和音频滤镜设置到 mpv 参数。
- 原生弹层改为带细边框的石墨渐变卡片，选中行使用蓝色强调面与勾选标记；比例菜单读取实际 mpv 属性标记当前值。
- 已通过 Dart targeted analyze、MSVC `/W4 /WX` 及 Windows Release 构建；gpu-next/libplacebo DLL 已重新安装。需在实际播放窗口中复核字体外观及各项媒体设置。
- 顶部改为窗口内左右各 16px 的全宽锚定布局；剧名组始终在左，网络速率位于右侧窗口按钮之前。底部运输控件仍保持适中的居中宽度。
- 弹层高度上限为 360px，支持滚轮、上下键和 Page Up/Page Down；播放菜单如实显示弹幕与片头片尾设置在 Windows 原生窗口中的可用状态，不将尚未实现的原生弹幕/片段跳转伪装为已生效。
- 原生快捷键从 `yingji.player.shortcuts` 读取并覆盖默认映射，不增加额外的快捷键菜单按钮。
