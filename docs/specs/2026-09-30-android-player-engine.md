# Android 播放引擎选择

- 日期：2026-09-30
- 状态：已实现
- 平台：Android；Windows 回归验证

## 目标与流程

Android 未设置时使用 ExoPlayer；设置 / 播放器可选择 ExoPlayer 或 mpv，下次播放生效。详情、服务器和继续观看入口遵守同一偏好，mpv 不再被 Dolby Vision 自动分流覆盖。

## 技术与数据

复用现有 Media3 SurfaceView Activity，普通视频不要求 Dolby Vision 能力。沿用 URL、鉴权请求头、恢复位置和返回观看记录。新增 `yingji.player.android-engine`（exo / mpv），缺失或无效默认 exo；其他键与观看记录格式不迁移。不得记录鉴权头。

## 兼容与边界

Windows 原生 libmpv 不变。Exo 使用原生控制栏与内嵌音轨/字幕；Mova 弹幕、在线字幕、扩展缓存和播放器内选集仍属于 mpv 功能，设置中明确说明。Exo 返回后保存本机进度；实时服务器/Trakt 同步尚未接入，不将其描述为功能完全一致。切换 mpv 可恢复原有功能。

## 验收与验证

- 默认 / 无效偏好选择 Exo；显式 mpv 选择 mpv。
- 两个播放入口均应用偏好，传递鉴权与进度；失败提示可返回设置切换。
- 格式化、静态分析、桥接与偏好测试、Android 构建和安装。
- Windows 构建并本地部署；不提交、不推送、不发版。
- 真机设置选择与持久化检查；无配置来源时不声称实际视频验证通过。

## 风险与回滚

设备解码器与封装支持依 Media3 / 系统而定；设置切换 mpv 即为恢复路径。新增偏好对旧版无影响。

## 实现记录

复用现有 Media3 Activity；增加通用 Exo 通道绕过仅 Dolby Vision 的能力限制。两个 Dart 播放入口接入同一默认偏好和退出进度保存。Android 构建、安装通过；3 项新桥接/玻璃测试及既有 Dolby Vision 测试通过。静态分析无错误/警告，有仓库既存 info 提示。测试版无服务器配置，实际片源播放、字幕、设备性能尚未验证；正式 Android 版缺少签名密钥，不覆盖，安装独立测试版。
