# 播放期间隐藏 Windows 主窗口

## 基本信息
- 日期：2026-10-10；平台：Windows；状态：已实现、已测试构建部署，实际窗口交互待用户复测。
- 目标：原生播放器进程启动成功后隐藏 Mova 主窗口；播放器退出或异常终止后恢复、聚焦原窗口，保持页面与滚动状态。
- 非目标：不退出 Flutter、不更改路由、不修改播放取流或 Android 行为、不发布。

## 技术与兼容
- 复用 WindowHost / window_manager 隐藏和恢复窗口；统一 WindowsNativePlayer.play 入口覆盖首页与详情页。
- 启动进程失败不隐藏；退出后立即恢复，不等待服务器同步或缓存清理；finally 保障异常路径恢复。
- 无新持久化键、协议或数据迁移。回滚仅移除本次窗口控制。

## 验收与验证
- 自动化验证窗口通道 hide/show/focus 调用及移动端隔离、启动/退出接线；执行静态检查、Windows 构建。
- 真机需验证普通/最大化窗口播放与退出、异常终止、切集不闪出主窗口、原页面和滚动位置保留。
- 不改变材质和布局；性能帧率对照、真实媒体操作与正式候选长测未完成时不标记上架合格。

## 实现记录
- 新增 WindowHost.hide，统一播放入口在 Process.start 成功后隐藏；退出后立即恢复，并在 finally 兜底。不移除页面或关闭应用。
- 新增 2 项窗口通道/源码接线测试通过；完整 Flutter 回归 445 项通过；涉及文件定向静态检查无问题；Windows release 构建通过、git diff --check 通过（仅换行提示）。测试包含插件调用，不等于实际窗口视觉验收。
- 本地 Windows D:/Mova 已覆盖部署；进程检查确认已退出，四项主要文件哈希一致；恢复受校验 gpu-next DLL，保留用户数据。Android 未部署，不改版本，无提交推送发布。
- 待实测：普通与最大化窗口各重复 3 次启动/退出、异常退出、切集、键盘焦点、页面位置保留。未采集帧率基线或完成此前播放管线长测；不标记正式上架就绪。
