# 详情页完整季集目录与按选集搜索

- 日期：2026-09-28
- 状态：已完成
- 影响平台：Windows、Android

## 背景与目标

当前季集列表由服务器聚合命中的播放文件生成，导致未入库、未匹配或超时的季集直接消失。进入详情页又会扫描整部剧。改为显示 TMDB 提供的完整已公布季集目录；资源搜索只针对当前选中集。

## 用户流程与界面

进入剧集详情先加载作品目录；有当前作品的本地播放记录时选最新记录的季集，否则选目录最早季的最早集。选中集立即搜索所有已连接服务器中这一集的资源；切季后选中该季第一集。切换、手动重搜均只针对当前集。季集目录不因没有服务器文件而隐藏；无资源显示可信空态。保留现有宽窄屏布局与鼠标、触控交互。

## 数据与接口

- 季集目录来自 TMDB 的剧集详情和季详情；不把元数据伪装成可播放文件。
- Emby/Jellyfin 按剧集父条目匹配，再通过 `Shows/{Id}/Episodes?Season=n` 只读取选中季并按集号精确过滤。WebDAV 搜索仍依赖现有文件目录解析，在本机按季集过滤。
- 不改持久化键、服务器协议或原有缓存结构；旧的全剧缓存可读，但不能代替新的按集搜索。
- 单服务器失败不阻断其他来源；异步旧请求不得覆盖新选中集结果。

## 验收标准

- [x] 真实元数据中所有已公布季集均可浏览，包括无播放资源的条目。
- [x] 无播放记录选最早集，有播放记录选最新记录集。
- [x] 进入详情、切季、切集、重搜仅聚合选中集；资源列表不混入其他集。
- [x] 每个来源完成后立刻显示命中资源，慢来源不阻塞已返回结果；无命中的来源不创建占位卡。
- [x] 失败可重试，不显示虚假播放资源或敏感信息。

## 验证计划与风险

自动测试覆盖默认选集、按季查询/过滤及快速切集；运行 format、analyze、Flutter tests，构建并部署 Windows。Android 共用逻辑通过测试验证，设备人工检查待执行。TMDB 请求失败时保留服务器已知条目并显示恢复提示，不推测不存在的季集；服务端错误可能造成该集资源暂不可用，但不会影响目录。

## 实现记录与限制

TMDB 全季目录与服务器播放资源分离，季详情按需读取；Emby/Jellyfin 按选中季查询并只保留选中集，所有服务器并发搜索，并在每个来源返回后立即更新资源区。WebDAV 按真实文件名的常见季集格式匹配，但其现有 `Depth: 1` 与最多 100 个文件的列表能力仍是覆盖上限。进入详情及切集均丢弃过时搜索结果。播放器保留完整剧集目录但只预聚合当前集；Windows 原生播放器的上一集/下一集、自动连播、片尾跳过和剧集菜单统一按条目状态分流：有 URL 时原地 `loadfile`，空 URL 时把季集编号交回 Flutter 即时聚合后重建播放器，不再向 mpv 加载空地址，也不扫描全剧。Android 真机与真实服务器《辛普森一家》数据尚待人工验证。

## 2026-09-29 原生播放器跨集切换补充

- 根因：播放器展示的是完整目录，但没有预先聚合的集 URL 为空；剧集菜单会按需回传季集，而控件上一集/下一集、连播及片尾跳过原先仍直接对空 URL 调用 `loadfile`。
- 修正：以上入口统一经 `SelectPlaylistEntry`。有地址时原地加载；无地址时正常关闭原生播放器并回传目标季集，由 Flutter 聚合该集后重启。自动连播使用目标集自己的进度；手动切集失败时保留当前播放位置。
- 验证：`flutter analyze` 通过（19 条既有 info）；全量 `flutter test` 有 3 项失败，分别为 `detail_origin_transition_test`、`discover_scroll_virtualization_test`、`glass_uniformity_test`，与此次 Windows 原生切集代码无关。Windows Release 构建及本地部署完成；部署版集成探针的未聚合上一集、下一集用例均通过（各 1/1）。Android 真机与线上服务器真实聚合流程未执行。
