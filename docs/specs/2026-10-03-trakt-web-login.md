# 双端 Trakt 网页授权

- 平台：Windows / Android；状态：已修改、构建及部署，真实登录待实测。
- 目标：两端通过 Trakt 官方 OAuth 登录页登录（可选择邮箱），同意授权后自动保存连接；安卓不再使用设备码。
- 技术：复用现有授权码、随机 state 和本机 loopback 回调，固定 127.0.0.1:43829/trakt/callback，保持 Worker 允许的 redirect_uri 完全一致，不修改或部署后端。不使用 WebView 收集账号密码。
- 用户流程：点击连接自动打开系统浏览器；等待授权、取消/超时/失败可重试。Windows 返回前台；安卓系统可能要求用户返回应用，但授权结果自动处理。
- 数据：沿用 access/refresh/expiry 键和令牌交换，现有设备码授权会话不清除；无迁移，无权限扩张，不记录 code/token。仅本机监听，不对局域网开放。
- 验证：回调错误 state、缺少 code、取消、端口清理及 token 保存测试；双端构建、部署；真实 Trakt 登录和安卓浏览器后台 loopback 回调需实测。
- 风险：浏览器可能限制 HTTP loopback/后台网络，或系统杀死后台应用。失败明确提示并重试，不能宣称真实授权已验证。回退授权入口即可，无数据回退风险。
- 不包含：菜单持续卡顿、APK 渠道签名问题。
- 实施记录：共用授权入口改为 Windows/Android 走既有 loopback 网页授权；未改 Worker 或凭据缓存。12 项 Trakt 测试通过，新增缺少 code 的拒绝断言；静态检查无错误/警告，21 条已有 info，格式及 diff 检查通过。Windows 已部署 D:\Mova；OPPO f9f3a649 保留数据安装 Success（com.taohua.mova.debug / 3.1.119 / 130）。没有登录用户账户、没有替用户授予第三方访问权限；授权拒绝、后台杀进程、安卓浏览器实际回调与自动连接未实测。未提交、推送或发版。
