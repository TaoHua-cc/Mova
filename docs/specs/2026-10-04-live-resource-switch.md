# 同窗口资源切换与续播记录复核

- 影响：Windows资源切换；双端继续播放共享读取与投影链路。
- 原因：原生资源菜单显式关闭窗口，详情页循环重启；尚需核对用户缺失的稳健115记录身份。
- 方案：复用同窗口剧集解析协议、地址及独立鉴权更新机制；应用提供资源解析回调，保留位置，先保存旧资源进度；失败留在原窗口并提示，不退出重开。旧无回调调用兼容保留。
- 兼容：不改持久化键、缓存格式、版本或外部服务器协议，不新增依赖。不得将本地/模拟投影当成完整UI验证。
- 验收：切换服务器资源窗口/进程不变，位置延续，旧新服务器鉴权隔离，记录可靠保存；失败可恢复。真实查询、合并、隐藏及同剧去重逐段核对稳健115。
- 验证：针对性回归、静态检查、Windows release构建、本地安装及用户切换实测；共享续播若需修改则同步构建部署安卓。
- 风险：资源规格改变可能短暂缓冲；同窗换源不承诺无缝。尚未完成长测，不能标记上架就绪。状态：定位/实现中。
