# 观看进度即时刷新

Windows 原生播放每 5 秒及退出保存实际进度，暂停/切集沿用最终采样。WatchStateStore 写入后发轻量 revision；首页和详情订阅，仅读本地、不等待网络，不重建导航和滚动控制器。服务器最终回报异步进行并保留失败待同步 mediaId（新独立偏好键，不存令牌），下次首页加载重试；限制重试，不让旧网络请求阻塞本地刷新。最新本地记录优先用于当前预览。

实际队列存 sourceId 与 serverItemId 组合，不复制媒体 URL 或令牌；键 yingji.watch-sync.pending-items，下次首页初始化恢复队列，单次最多三次尝试、失败保留。切换本机模式停止回报。

共享页面影响两端；持久观看记录格式不变，新队列键可忽略回滚。验证记录通知单元测试、退出回归、分析及双端构建/本地部署；断网、退出后四处预览和真实服务器回报需实播验收。

实施结果：15 项记录相关测试通过，静态检查无错误/警告（20 条 info，包含一条新括号风格提示），双端 Release 构建成功。Windows 已部署 D:\Mova 并核对 app.so；平板测试包核对身份后安装。真实退出即时刷新及断网重试尚待用户实播验收。周期写入目前仅 Windows 原生入口新增；Android 沿用已有保存周期，共享页面通知同样生效。
