# 弹幕轨道与帧刷新修复

- 日期：2026-10-01
- 状态：实现并完成定向测试
- 平台：Android Exo / mpv 共用 Flutter 弹幕；Windows 原生弹幕独立。

## 问题与目标

按秒持续入场后，随机轨道会重叠；宽度不同导致速度不同而追尾。
Exo 每 250ms 位置事件都会重建播放页；旧插值在采样延迟时停止。
目标是弹幕尾部留出间距，新弹幕及时入场，播放中按 vsync 平滑刷新。

## 实现

按实际文字宽度预留轨道入口，滚动弹幕采用相同速度，满轨道的弹幕直接过滤。
顶部和底部固定弹幕分别保留独立行；滚动区域避开它们。
轨道决策和文字布局缓存，避免逐帧重新布局；缓存逐项淘汰。
位置样本用实际播放倍率插值并缓慢纠正采样误差。
Exo 仅在轨道、时长、缓冲或播放状态变化时更新整页。

## 兼容与验收

不改变弹幕接口、缓存格式或设置键。密度仍按秒限制，轨道满时不延迟补播。
验证同轨道短长文字间距、过滤弹幕不重放、固定行、回退进度和布局缓存。
使用 Release AOT 测试包部署平板；真机连续播放效果与帧耗时需要复核。

## 验证记录

12 项弹幕时间轴、轨道与 Android 播放器定向测试通过。定向静态检查无错误。
平板 Release AOT 播放《兰香如故》并开启弹幕：连续 6 个一秒窗口约
50.8–52.3 fps，build 平均 0.37–0.50ms，raster 平均 17.55–17.88ms，
raster p95 20.14–22.11ms。仍存在超过 20ms 的绘制帧，不能据此宣称完全无掉帧；
本次没有旧包同场景对照，也没有验证 Windows 原生播放器。
