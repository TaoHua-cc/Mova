# 榜单海报尺寸及服务器图标持久化

- 双端共享修复，不改版本，不提交或发布。
- 榜单卡片固定评分栏28像素，未知评分留空不造数据，避免海报占用空出的高度。
- 页面与Windows播放器共用server_marks支持目录缓存；按完整URL、来源ID及自定义标识SHA256命名，解决旧截断名称碰撞。优先读有效图片，无缓存才联网，有界超时/大小；失败不永久记忆，显示原有兜底。旧缓存不删除，首次联网生成新名；不存鉴权。
- 手动图标更新只修改当前来源的图标字段；后台身份/自动图标更新保留最新手动图标，页面刷新使用持久列表，不发布旧快照。失败保留现有图标。

- 非目标：播放、服务器排序、实时背景渲染和发版。旧来源JSON保持兼容，新图标缓存回滚安全。
