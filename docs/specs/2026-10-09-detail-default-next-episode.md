# 详情页默认选择待播集

- 复现：作品入口进入详情页，最近一集已播放完成，仍默认选中已完成集。
- 原因：detailInitialEpisode 直接返回最近记录集号，未使用 WatchState.isCompleted。
- 修改：默认入口已完成记录选择下一集；未完成继续当前集。已知季末跨到后续非空季第一集，已知全剧末集保留该集。明确指定集号入口仍优先指定位置。复用手动已播放或 92% 的现有完成判定；不改观看数据及持久化格式。
- 平台：共享 Windows/Android 业务代码。
- 验证：默认选集、续播及末端布局 19 项测试通过，包含手动完成、进度完成、未完成、跨季、全剧末集及显式入口。
- 未验证：真实服务端历史更新和双端实际安装后的入口行为；本次尚未构建/部署。季集数量未知时按下一集号处理，外部目录缺失仍需人工复核。
