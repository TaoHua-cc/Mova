# Windows 固定液态玻璃

- 日期：2026-10-03；状态：已实现、本地部署；仅 Windows。
- 目标：替换灰色遮蔽磨砂，统一清透底材、方向性高光、双层边缘与轻微厚度。滑块控制液态质感，不控制背景模糊或不透明度。
- 非目标：真实背景折射、背景取样、动画着色器；不修改安卓外观、不部署安卓、不改变按钮尺寸和操作流程。
- 方案：复用 brand.dart 材质与原生播放器公共绘制函数，Windows 平台分支；第二轮底材保持约 3.5% 近无色透明度，滑块只改变高光、边缘厚度。全局 0–40 持久化键保留，无迁移。
- 验收：两端材质测试、无取样回归、Windows 构建与本地部署；宽屏/窄屏菜单、鼠标和键盘保持原有布局，明暗背景可读性待人工验证。
- 风险：固定光学层只能模拟液态玻璃外观，不是真实光学折射；高反差背景仍需人工复核文字可读性。
