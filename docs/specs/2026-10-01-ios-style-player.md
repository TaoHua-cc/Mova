# iOS 风格播放器细化（Windows）

保留现有圆形按钮、鼠标命中范围、菜单和真实数据。普通按钮弱化描边，选中/悬浮提供更明确亮度；菜单采用连续分组底板、文字起点分隔线，移除普通行的卡片边框和图标小底板；音量、亮度、倍速 HUD 用图标与数值表达，保持连续操作更新与状态提示功能。

不修改解码、偏好键或 Android，不引入实时玻璃采样、第三方依赖或视频缩放动画。验证现有播放器回归、Windows Release 编译并部署 D:\Mova。人工需在宽窄窗口检查菜单分组、键盘焦点、连续调节及错误提示；编译不代表视觉验收。
