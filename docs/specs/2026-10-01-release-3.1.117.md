# Mova 3.1.117 发布

用户授权提交、推送双端修改并正式发版。版本 3.1.117+128，tag v3.1.117。范围：启动、Windows 固定玻璃播放器控件/菜单/提示、退出及周期进度保存、页面通知与后台服务器回报、Android 系统音量同步及 Exo 状态、剧集缩略图进度。观看记录格式保持兼容，新增待回报来源/项目 ID 队列键可被旧版忽略。
