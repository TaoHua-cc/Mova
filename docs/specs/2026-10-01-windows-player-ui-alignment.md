# Windows 启动与播放器控件对齐 Android

- 日期：2026-10-01
- 状态：已完成实现与本地部署，窄窗交互待人工补测
- 影响平台：Windows；Android 使用原生启动屏

## 目标与方案

启动只保留居中图标，删除光环、扫光、文字、呼吸和页面缩放，不人为延长启动。
Windows 保留原生 libmpv 内核和窗口功能，底部对齐 Android：40px 圆形按钮、4px 间距、左右独立玻璃胶囊，左侧播放与时间，右侧音量与工具。字幕和音轨菜单独立。窄窗减少工具并放入更多，绘制和点击共用布局。

## 兼容与非目标

不改播放协议、解码、持久化键或缓存。Windows 保留窗口按钮，不照搬 Android 旋转按钮。无数据迁移，可安全回退。

## 验收与验证

- 启动等待仅显示居中图标，无循环动画。
- 宽窄窗口控件不重叠，播放、切集、音量和工具绘制与点击位置一致。
- 字幕和音轨菜单不混装。
- 启动测试、原生回归测试、静态检查和 Windows Release 编译。
- 本地部署 D:\Mova；人工检查宽窄窗、鼠标与快捷键、菜单滚动。

## 风险

原生绘制与 Flutter 不是同一渲染器，需检查 DPI 和文字布局；不增加实时视频背板采样。
