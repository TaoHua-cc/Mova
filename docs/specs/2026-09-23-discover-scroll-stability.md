# 发现页滚动内容稳定性

- 日期：2026-09-23
- 状态：已完成
- 影响平台：Windows、Android（共享 Flutter 界面）

## 背景与目标

发现页与完整榜单滚动时，海报和图标像被重新加载，滚动末尾会顿一下。目标是在回收列表项后立即显示已缓存图片，并避免滚轮停稳时集中重建或加载可见内容。

## 用户流程与界面

保持现有栏目、榜单、空态与加载提示。Windows 鼠标滚轮和 Android 触控滚动不应使玻璃按钮突然切换材质；已缓存海报回到视口时不再重复淡入。窄屏与宽屏均保持原有布局和虚拟化列表。

## 数据与接口

不改网络接口、持久化键、缓存格式或真实数据来源。图片继续使用现有内存与磁盘缓存；首次下载仍按原有错误占位处理。

## 技术方案

- 发现页栏目扩展定时器只在首次达到阈值时启动，不在每个滚动帧重置；触发时按当前位置计算所需栏目。
- 保留现有滚动期间暂停玻璃采样的策略；移除后实测滚动约 72fps，代价过高。此次优先消除图片淡入与滚动尾部集中加载。
- 海报与平台图的缓存图像直接显示，不再在列表项重新挂载时播放默认淡入动画。
- 发现页与完整榜单启用稳定玻璃作用域：作用域内的图标和控件始终执行真实背板模糊；滚动状态不再关闭滤镜，因此起步/停稳不会出现材质跳变。小型圆形图标使用同一外观模糊滑杆的 55% 半径，减少颜色被完全抹平的实心感；共享滚动状态仅用于在滑行期间冻结流动背景，停稳后从原相位继续。
- 首页/发现、继续播放全部列表、榜单、搜索、来源、片单、日历、设置，以及片单详情、媒体库、人物详情统一使用共享平滑滚动器；Windows 使用平滑滚轮物理，Android 保留触控回弹。
- 发现页每个栏目使用独立 `ValueNotifier` 发布数据；后台刷新只重建发生变化的栏目，不再让整张发现页连同全部海报一起重建。
- 主壳层统一进入稳定玻璃作用域，侧栏与顶栏不再对持续流动的背景逐帧重复执行离屏模糊；透明材质、边缘高光、阴影和光泽仍保留。
- 首页海报通过原有 `ShaderMask` 随滚动位置连续淡出，固定流动渐变始终铺底接管；海报完全淡出后不再参与绘制，返回首屏时平滑恢复。
- Windows 滚轮滑行与 Android 触控滚动期间冻结流动渐变在当前相位，停止后原位继续，避免背景动画和列表同时抢占光栅线程。

## 兼容与迁移

没有数据迁移。Android 没有 Windows 平滑滚轮，但共享图片与玻璃行为一致；回滚代码安全。

## 风险与回滚

曾尝试让玻璃过滤器在滚动期间持续工作，Windows profile 滚动采样降至约 72fps，因此已撤回。按钮在滚轮停稳时仍会恢复实时模糊，可能有轻微材质变化；后续若仍明显闪变，应单独优化玻璃层级与过渡，不能以持续昂贵的全屏采样换取稳定外观。

发现页与完整榜单后续改为局部稳定玻璃：这些长列表不在停稳时恢复滤镜，避免滚动结束的批量重合成；代价是列表内部玻璃不采样动态背板，但导航与其他页面不受影响。

## 实现记录

已完成栏目预加载计时器与图片淡入修正，定向测试 3 项通过，静态检查无错误/警告（18 条既有 info）。Windows release 构建成功，已部署到 `D:\Mova\mova.exe`。profile 自动往返滚动样本仍受当前加载栏目数影响，约 79fps，不能据此宣称整体滚动帧率已达标；本次主要修复重复淡入和滚动尾端集中加载。Android SDK 缺失，Android 实机与窄屏触控未测。

追加稳定玻璃后，定向测试与流动背景测试共 4 项通过。Windows Profile 的本轮输入发送量异常偏低，滚动阶段平均值不具可比性；但滚动结束后的连续 6 个窗口约 162–180fps、`raster_p95` 约 3.5–4.3ms，没有出现停稳后恢复玻璃滤镜造成的额外峰值。最终 Windows Release 已重新部署。

全页统一优化后，新增结构回归测试覆盖 11 类纵向页面，并验证发现页按栏目局部更新；定向测试共 6 项通过，静态分析无错误/警告（18 条既有 info）。主壳层稳定玻璃的 Windows Profile 复测需在已运行的 Mova 退出后执行。

最终 Windows Profile 在 1264×681、170Hz、8 秒自动往返滚动下，移除发现区背后的首屏海报合成层后，滚动平均值由约 52fps 提升到约 75fps；停止后的窗口约 160–183fps。高刷目标下仍以光栅线程为主要限制，但已超过 60fps 目标，且合成负担不再由不可见首页海报造成。

启动优化：将首页发现栏目的初始请求数改为 0；滚动超过首页约 55% 视口后，按 396px 栏目高度逐项预取，数据与海报预热不再和启动首屏争用网络及解码资源。`home_progressive_loading_test.dart` 定向测试通过。

### 海报滚动抖动补充修复（2026-09-23）

- 发现列表滚动期间清除卡片 hover 状态，并将缩放/抬升动画立即收回；滚动事件经过海报时不再启动阴影与缩放。
- 榜单卡片在滚动开始时立即移除悬停展开预览，避免 overlay 跟随列表重复进出；停稳并重新移动鼠标后原预览仍可用。
- 定向测试覆盖上述交互；Windows Release 已部署，播放器 DLL 保持原文件。
- Release 实机采样：1264×681、170Hz、8秒 900px/s 往返滚动，最终版平均约 116.9 FPS（前次记录约75 FPS），`raster_p95` 约16.8ms，慢帧占比约59.3%。采样波动较大，但明显超过85 FPS验收线；高刷设备仍受光栅线程限制，不能称为完全顺滑。
