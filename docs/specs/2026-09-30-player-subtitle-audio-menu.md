# 播放器字幕与音轨菜单优化

- 日期：2026-09-30
- 状态：已完成
- 影响平台：Windows 原生播放器

## 背景与问题

播放器的音轨和字幕入口各自显示独立菜单；二级菜单使用视频背板采样，背景材质与播放器圆形控件不稳定一致。字幕搜索应留在当前菜单流程中。

## 目标

- 从字幕或音轨控件均打开同一个字幕与音轨面板，显示当前媒体实际轨道。
- 在线字幕搜索结果继续在同一面板内展示，并可返回轨道列表、下载和应用。
- 二级菜单采用固定深色雾面玻璃，不在打开、切换或滚动时读取视频帧；透明程度受现有全局外观设置控制。
- 保持现有播放器圆形按钮外观与排列。

## 非目标

- 不改变字幕服务接口、播放器轨道选择协议、播放进度、媒体缓存或 Android 播放页。
- 不修改播放器操作提示材质。

## 用户流程与界面

用户点击字幕或音轨按钮，打开“字幕与音轨”菜单。菜单按字幕和音轨分组显示播放器当前实际轨道、选择状态及自动选择操作。点击“在线搜索字幕”后同一面板切到搜索状态，返回时重新显示字幕与音轨；选择结果后按现有流程下载并应用。面板内列表超出可视高度时沿用现有滚动，不显示滚动条。

## 数据与接口

- 输入来自当前 mpv `track-list` 和现有字幕搜索结果。
- 不增加持久化键、缓存格式、网络接口或凭据。
- 搜索为空、加载中和失败状态沿用现有真实来源状态文案与恢复入口。

## 技术方案

- Windows：复用现有 `PanelItem`、面板锚点、滚动、选择和字幕搜索通道；为媒体轨道行增加紧凑高度。
- 只替换通用二级菜单面板表面、描边与文字/行状态配色；原生圆形控件不改样式。
- 新增固定雾面绘制入口，读取既有 `g_glass_blur` 计算静态 alpha；移除菜单的缓存背板截取路径，控件和顶栏保留当前既有呈现。
- Android 继续使用现有 Flutter 播放页，不受 Windows 原生菜单改动影响。

## 兼容与迁移

- 现有 mpv 轨道与字幕搜索消息兼容，无数据迁移。
- 仅 Windows 原生菜单视觉与字幕/音轨入口合并；Android 行为不变。
- 回滚只需还原菜单绘制和 `ShowTrackMenu`。

## 验收标准

- [ ] 字幕按钮和音轨按钮均打开统一菜单，显示实际轨道和正确勾选状态。
- [ ] 菜单固定材质随外观设置变化，打开和滚动不触发菜单背板取样。
- [ ] 在线搜索、返回、下载及应用均停留在同一面板流程。
- [ ] 原有控件按钮的形状、大小、图标及排列保持不变。
- [ ] 空字幕/空音轨及较长列表有清晰状态并能滚动。

## 验证计划

- 自动：编译 Windows Release 包；当前轮按部署要求跳过全量 Flutter 测试。
- 人工：在亮暗视频画面分别打开菜单；测试字幕/音轨切换、搜索、返回、下载应用、滚动和全局模糊设置；确认按钮外观未变且播放帧率不受菜单开闭影响。

## 风险与回滚

- 合并列表比原单项菜单更长，小窗口可能滚动；列表行采用紧凑高度并沿用现有面板滚动机制。
- 透明雾面在亮暗画面下对比度不同；使用固定深色高不透明度和浅色文字，确保可读。
- 回滚时恢复旧面板构造和背景绘制函数，不涉及用户数据。
