# Windows 播放器置顶、拖动预览与取消跳过

- 日期：2026-10-05
- 状态：已实现并部署，真实媒体交互待复核
- 平台：Windows；共享设置保留 Android 原有行为，本次不部署 Android。

## 目标与流程

播放器右上角新增同材质圆形置顶按钮，点击切换并明确显示选中状态。拖动进度条显示真实画面与目标时间，松手后才改变主播放位置。设置 → 播放器行为提供预览开关。服务器已生成缩略图优先，缺少时独立低分辨率解码尝试抽帧，失败退回时间显示，不用海报伪装帧。

设置 → 自动跳过提供“取消后保留跳过按钮”，默认开启。取消只停本段倒计时；开启时保留手动跳过，关闭时隐藏。本段结束或切集后清除状态。

## 接口、兼容和安全

新增偏好 yingji.player.seek-preview、yingji.segment.show-skip-after-cancel，缺省 true，不迁移旧键。新增 MOVA_SEEK_PREVIEW 请求/响应，包含请求序号与播放列表索引，过期结果丢弃。服务器请求遵守对应服务器代理设置、鉴权和超时；不记录地址/令牌。临时图片在播放器结束时移除。Jellyfin Trickplay 瓦片、Emby BIF 为服务器来源。

## 实现与风险

复用现有 Windows libmpv、固定玻璃和字体，不增加依赖。预览串行处理、节流、限制数据体积；解码不触碰主 mpv 实例。第二解码器仍可能增加网络/CPU，提供即时关闭。置顶使用 Windows 原生窗口层级，不改系统设置。

## 验收与验证

- 连续拖动保留同一资源最新完成的真实帧，并显示该帧对应时间；松手、切集、切资源、关闭预览后丢弃旧生命周期结果，不显示其他集画面。
- 置顶/取消置顶、最小化恢复与全屏正常；窗口窄时无重叠。
- 取消自动跳过不再倒计时，开关分别保留/隐藏手动入口。
- 自动测试覆盖缩略图解析、缺失/损坏、时间边界与接线；执行静态检查和 Windows release 构建。
- 人工需测试有/无服务器缩略图、HDR、代理资源和连续拖动时主视频掉帧；未实测不声称性能达标。
- Android 无新增原生功能，不展示无效设置；共享代码回归测试。

## 实现记录

### 实际修改

- 原生 Windows 顶栏增加置顶按钮、明确选中态和提示，保留最小化/最大化/关闭位置。
