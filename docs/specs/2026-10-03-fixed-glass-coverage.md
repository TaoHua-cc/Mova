# 外观统一控制固定磨砂遮蔽

日期：2026-10-03；双端；已实现并本地部署。

## 问题与目标
上版固定玻璃仅改变高光范围，底材 alpha 恒定，右键菜单与按钮没有用户要求的明显遮蔽变化。此次修复所有公共底材函数和原生播放器固定材质，采用同一曲线：0/20/40 对应约 6%/52%/98% 不透明度，保持中性 RGB(88,96,98)，白色反光浓度不增加。不读取任何背景像素。

## 范围与兼容
菜单、卡片、按钮、提示、弹窗与播放器自动跳过均复用公共函数。选中态保留珍珠白以保护状态可读性。影片海报、页面主画布不是控件玻璃，不用此曲线覆盖。持久化键、0–40 范围、网络与数据格式不变，无迁移。

## 验收与验证
逐级 alpha 单调增加，左右端点明显区分；颜色保持中性，反光不随遮蔽变白；显式旧取样参数也不能启用 BackdropFilter。Widget 测试检查开放菜单/按钮外观变化与无取样；双端构建部署，真实不同背景与设备尺寸待人工复核。

验证结果：328 项测试通过；静态检查只有既有 20 条 info，无错误或警告。Windows release 已覆盖 D:\Mova 并校验 exe 哈希一致；Android release 已通过 install -r 覆盖平板 com.taohua.mova.debug，保留数据。设置显示磨砂百分比，持久化范围不变；没有发布或推送。实际视觉效果、不同 DPI 与触控场景仍需人工确认。
