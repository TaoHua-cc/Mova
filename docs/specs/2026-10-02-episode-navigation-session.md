# 详情页集号导航与会话搜索

日期：2026-10-02；影响：Windows / Android；状态：已实现。

## 目标与用户流程

“集”标题下、剧照上新增已播出集号横向列表，支持鼠标拖动、触控和键盘选择。点击仅选集并定位，不直接播放。无播出日期的目录不伪造已发布状态。
本次详情页内每季每集自动聚合一次，空结果和失败同样保留；切回复用，重新搜索按钮强制刷新。离开详情页后会话失效。

## 技术与兼容

复用现有选集、居中、横向拖动和品牌组件；内存保存每集搜索任务和结果。后台完成不覆盖其他集的界面，不更改持久化键、网络协议、版本或凭据。

## 验收与验证

- 集号只显示真实已发布目录；选集与预览同步。
- 重复选集不重复请求，手动重搜可恢复失败；页面实例不共享任务。
- 格式化、静态检查、自动测试及双端构建；本地覆盖部署保留数据。
- 人工待核对：宽窄窗口、鼠标/触控拖动，快速切换集和重搜，退出后重新进入。

## 风险

资源在当前会话中变化需要手动重新搜索；未知播出日期不列入集号条，原剧照入口仍保留。

## 实现记录

采用详情页实例内的任务与结果映射，按季/集区分；并发重搜以修订号隔离旧结果。集号条复用鼠标拖动组件，点击调用原选集及剧照定位流程。
静态检查无错误/警告（20 条已有 info）；315 项测试通过。Windows Release 与 Android Release 构建成功，已覆盖 D:/Mova 和连接平板的既有 Mova 包，保留数据。
新增测试为源码接线回归检查；真实服务器请求次数、鼠标/触控体验及窄屏效果尚需人工复核，不将其记为自动测试通过。
