# 滚动材质、日历平台与剧集定位修复

日期：2026-10-02；平台：Windows / Android；状态：已实现并本地部署，待人工视觉与帧率复核。

## 平板玻璃采样对照与圆形按钮固定材质

OPPO OPD2401 滑动基线：build 平均约 0.7–2.3ms，raster 平均约 17–22ms、峰值约 61ms。临时跳过全部玻璃采样后，多段连续滑动达 120–143fps、raster 约 3–5ms，用户确认不卡。单独恢复首页海报仍流畅，多段约 115–145fps、raster 约 3.5–4.5ms；不能将所有收益归因于圆形按钮。

用户要求逐项恢复，先将共享 Flutter 圆形玻璃改为固定浅色磨砂：使用现有 chrome 色调、depth 渐变、描边与选中高光；外观滑杆调整浓度，不创建 BackdropFilter。矩形玻璃与 FrostSurface 源码不修改；本次平板诊断构建保留 shell,frost,rect 跳过参数，首页海报正常，圆形材质由正式源码实现而非 circle/glass 跳过参数。不变更偏好键或数据格式。Windows 共享组件也受此源码影响，但本次不部署 Windows；原生 Windows 播放器不变。

## 目标与验收

后续按用户要求将 YingjiGlassSurface / YingjiGlassCard / GlassPanel 的默认背景改为清透固定磨砂，保留显式 sampleBackdrop:true 的可测旧路径；播放器既有固定材质不变。本次平板构建只保留 frost 诊断禁用，矩形组件不再依赖 rect 跳过参数。独立 FrostSurface 源码不改，实际使用处包括服务器卡片、片单卡片、搜索框/服务器搜索结果、空态/错误提示、服务器图标选择项和关于页介绍卡片；设置多数分组 glass:false 原本不采样。首页海报与背景保留。

圆形固定磨砂第二次视觉调整：用户反馈首版白雾偏重，将非选中底色范围由 16–38% 降为 7–19%，默认普通图标约 9.4%；保留 depth、高光、描边和珍珠白选中态，不恢复背板采样。平板构建继续保留 shell,frost,rect 诊断参数，其他组件仍待逐项恢复。

轮播补充修复：后台元数据重读不再无条件 `_hero=0`，按当前影片 ID 与类型保留海报（列表重排也保留，影片被移除才回退首项）。Android 手势开始暂停自动轮播，结束/取消恢复；选点或换图重新开始完整计时。双端统一 100ms 圆点更新及插值，仍只刷新 RepaintBoundary 内指示点。单元测试覆盖重排、同 ID 不同类型、移除与空列表；真机手势、后台刷新及显示流畅度待部署后复核。

截图澄清：榜单全部列表和详情页最上方窗口控制横条需要透出滚动内容。榜单等整页列表 Scaffold.extendBodyBehindAppBar 会向 body 注入顶栏高度的 MediaQuery padding，原 SafeArea 消耗它后仍把列表裁在顶栏下方；改为 body SafeArea(top:false)。详情页原 Column 将顶栏与滚动列表上下分隔，改成全尺寸滚动层加顶栏透明叠加，初始内容上边距保留 82+10。按钮和窗口拖动区域保留；不改变弹窗其他材质。318 项测试通过；真实宽窄屏滚动穿过顶栏与点击命中需人工复核。
