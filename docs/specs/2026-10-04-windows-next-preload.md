# Windows 下一集有界预加载

- 日期：2026-10-04
- 状态：实现中
- 平台：Windows；Android 播放管线本次不改。

## 背景与目标

用户确认片尾跳转现在可用，重点改为在跳转前缓存下一集开头。现有预加载仅接通代理资源，原生直连未接通，未解析剧集也无法准备。

## 方案与兼容

复用下一集预加载开关、提前分钟数、缓存容量和 VideoCacheStore。当前集保持原生直连；播放达到正片的 80%、进入既有提前时间、或真实缓冲终点达到有效片尾时，准备下一集。当前集缓冲不足/正在缓冲时不启动预加载。每次只准备下一集、上限 32 MiB；完成后仅该集通过已有缓存读取桥复用前缀，缺失部分按原服务器代理选择取流。不修改缓存格式或已有偏好键。

未解析资源使用只读的同服务器剧集查询，不修改详情页选集或当前资源。失败不影响当前播放，切集仍走现有按需解析。旧版可读缓存；回滚安全。不开第二个视频解码器。

## 非目标与限制

不承诺无缝/零首帧延迟，不改 Android Exo，不按时长猜测字节并截断文件。容器索引、无 Range 源、源站吞吐和网络波动仍影响切集。32 MiB 是字节上限，不等于固定播放秒数。当前集原生预读可能仍读取片尾；精确停止片尾取流需另行验证。

## 验收与验证

- 开关关闭/容量零/最后一集不准备；比例、提前时间和片尾缓冲三个入口均测试。
- 预加载不修改选集、不提前播放；过期结果不能覆盖当前集。
- 缓存前缀实际复用，缺失区间正确续取，HTTP/鉴权/代理保持一致。
- 格式化、静态检查、相关测试及 Windows Release 构建。
- 本地保留数据部署；同资源三次对照切集首帧、缓冲、网络请求和掉帧。未实测不能标为通过。
- 60 分钟播放长测、Android 跨平台编译及弱网真机验证未执行时记录，不宣称上架就绪。
