# 服务器卡片单边框与固定宽度

- 影响：Windows / Android；正式版 3.1.128。
- 原因：服务器卡片自身玻璃描边、悬浮位移与右键菜单外层状态描边叠加；Windows 布局仍按服务器数量拉伸整行。此前资源弹窗修复未覆盖此路径。
- 方案：服务器菜单关闭外层装饰，保留右键/长按、键盘及卡片本身反馈；服务器卡片悬浮不缩放或位移。Windows 最大宽度388、Android340，间距12，多余项换行，顺序沿用来源列表，不按延迟或媒体数量重排。
- 兼容：不修改持久化、网络、服务器列表顺序、播放管线；无迁移，回滚安全。
- 验收：1/2/多服务器在宽窄屏不拉伸；悬浮、聚焦、右键打开只有卡片自有边框；设置、删除、进入、线路菜单仍可操作。
- 验证：布局单测、共享菜单鼠标/菜单状态Widget测试及页面接线回归；完整测试、静态检查、双端发布构建。实际服务器页面宽窄屏人工验收未执行，不以编译代替视觉实测。
- 已修改并通过6项针对性测试；完整套件串行450项全部通过。两次并行套件分别出现缓存清理及网络缓存测试失败，缓存清理单独重跑通过，记录为测试稳定性风险，未改无关缓存实现。
- 静态检查无error/warning，5条既有info；格式化、diff检查通过。Windows release构建并部署D:/Mova，四个关键文件与构建哈希一致，保留数据。Android由正式发布流水线构建，本次未本地安装。
